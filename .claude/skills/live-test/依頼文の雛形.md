## 必ず守ること
- **ブラウザは `{利用者}` でログインしているはずです。ログアウト・ログインはしないでください**（同時に動いている別の担当も同じ利用者で流しているため）。**パスワードの入力は一切しないでください。** ログイン画面が出た・権限で断られたときは、そこで止めて報告してください。
- **自分で作ったタブ以外を触らないでください**（最初に `tabs_context_mcp`、次に `tabs_create_mcp`）。
- **入力は実クリック＋実タイピング**（`computer` の `left_click`・`triple_click`・`type`・`key`）。**選ぶ欄（select）は実クリック＋`Down`/`Enter`**。**`form_input` は使わないでください。** 日付の欄の打ち方は qa/04 §2-2 のとおりにし、届かなければ §2-2 の代わりを使って、項目ごとに書いてください。
- **クリックの前に必ずスクリーンショットを 1 枚撮ってください**（qa/01 の G-11・G-12）。**押す前のスクリーンショットとクリックを、1 回の呼び出し（`browser_batch` など）にまとめないでください**（スクリーンショットが失敗したまま押すことになる）。撮らずに押したクリックがあれば報告に書いてください。窓は別の担当と共有しているので、座標は撮り直してから取ってください（G-14）。
- **書けたか・何が残ったかは `sql` CLI で確かめてください**: `pwsh -NoProfile -File tools/clb/sql.ps1 -Query "SELECT ..."`。**`sql` CLI は単独で、1 本ずつ打つ**——シェルで `|`・`;`・`cd … &&` を繋がず、並列にもしない（qa/04 §2-0。SQL の文の中の `;` の話ではない）。**ハーネスの分類器や操作制限に拒まれたら、打ち直さず、別の道具で回り込まず、拒まれた字をそのまま報告に写してください**（列を変えた打ち直しもしない。その確かめを未達として次へ進む）。
- **共有のデータを一時的に変える手順（マスタの有効・無効など）は、変える直前に値を読んでください。** 手順が変える先の値に既になっていたら（変えた主は分からない——別の担当か、前の回の残り）、自分では変えず、戻しもしないでください。**自分で変えたものだけを、控えと突き合わせて戻してください。**

- **ファイル・フォルダの削除はしないでください。** **見た文字列は、そのまま報告に写してください（要約しない）。** 「伝票 N」は伝票番号、行の id は「id N」と書き分けてください。
