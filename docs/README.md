# ドキュメント索引 — 何をするときに何を読むか

> **ここが唯一の入口。** 目的の文書はこのページから引く。文書一覧ではなく**タスク起点の案内**である。
> 文書の書き方・`status` の意味・腐り防止の約束は [00_ドキュメント規約](00_ドキュメント規約.md)。

## 1. 実装する

| やること | 読むもの |
|---|---|
| **次に何をやるか知る／作業を再開する** | [05_実装計画と現在地](05_実装計画と現在地.md)（「次にやること」だけ読めば再開できる） |
| **会計の正しさを確かめる**（仕訳・訂正・締め・繰越） | [04_会計ドメイン設計](04_会計ドメイン設計.md) — 複式簿記の正しさはここで担保する |
| **消費税を実装する** | [06_消費税設計](06_消費税設計.md) → [消費税リサーチ](research/2026-08-23_消費税インボイス制度.md) |
| **画面の文言を書く** | [CLAUDE.md §2-7](../CLAUDE.md)（です・ます調・内部表現を出さない） → [ADR-0017](decisions/0017-仕訳と伝票の呼び分け.md)（「仕訳」「伝票」の使い分け） |
| **取引先マスタに何を持つか決める** | [07_取引先設計](07_取引先設計.md) → [取引先の識別番号と公表システム](research/2026-08-25_取引先の識別番号と公表システム.md)（法人番号は持てる・**個人番号は持てない**） |
| **登録番号の写しをいつの登録で引くか** | [07_取引先設計 §4-1](07_取引先設計.md) → [登録の効力を失う日](research/2026-08-26_登録の効力を失う日.md)（**公表される日付が最終日か初日かは未確認**。境界は含める側に倒した） |
| **スキーマを変える・稼働 DB へ配る** | [migrations README](../Designer/migrations/README.md)（変える手順・書き方の規則） → [ddl README](../Designer/ddl/README.md)（正典）。方式の経緯は [ADR-0020](decisions/0020-スキーマは現在形の正典で持ち変更は差分で配る.md) |
| **新しいマスタをどこに置くか決める** | [ADR-0019](decisions/0019-マスタは会計が生んだ概念かで分ける.md)。**「会計をやめても存在し続けるか」**を先に問う |
| **部品として分けるかを決める** | [ADR-0024](decisions/0024-部品の分割は束ねる相手抜きで使われる場面があるかで決める.md)（基準）→ [ADR-0025](decisions/0025-取引先を部品として分ける.md)（取引先への適用例） |
| **画面を誰に見せるかを決める・PageFrame を足す** | [ADR-0026](decisions/0026-画面は役割で分け玄関のページフレームを置く.md)（役割・玄関・権限の書き分け）→ [qa/01 の F-18〜F-24](qa/01_CLB静かな失敗.md)（**権限を書く前に必ず読む**） |
| **一覧の見せ方が標準では足りない** | [ADR-0027](decisions/0027-入力の一覧はラップモジュールとクエリモジュールで作る.md)（ラップモジュール ＋ クエリモジュール）→ [ADR-0022](decisions/0022-明細を並べる帳簿はクエリモジュールで作る.md)（帳簿の場合） |
| **取引先の名寄せを実装する** | [07 §2](07_取引先設計.md)（規則）→ [ADR-0028](decisions/0028-名寄せの親は同一人格の表明であり深さ1に固定する.md)（なぜ深さ 1 か） |
| **帳簿に何を残すか判断する** | [ADR-0018](decisions/0018-帳簿の記載事項は計上時に写して固定する.md)（記載事項は写して固定・資格は有効期間で持つ） → [消費税リサーチ §6・§8](research/2026-08-23_消費税インボイス制度.md) |
| **帳簿を作る・法定検索を確かめる** | [電帳法リサーチ §3.5・§13.1](research/2026-08-23_電子帳簿保存法.md) → [取引金額での検索の調査](research/2026-08-24_仕訳の取引金額での検索.md)。帳簿は明細 1 行＝1 レコードのクエリモジュールで作る（`Designer/Design/Modules/Books/`。[ADR-0022](decisions/0022-明細を並べる帳簿はクエリモジュールで作る.md)） |
| 新しい機能を検討する | [03_機能スコープ](03_機能スコープ.md) → 該当する [ADR](decisions/README.md) |
