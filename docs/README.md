# ドキュメント索引 — 何をするときに何を読むか

> **ここが唯一の入口。** 目的の文書はこのページから引く。文書一覧ではなく**タスク起点の案内**である。
> 文書の書き方・`status` の意味・腐り防止の約束は [00_ドキュメント規約](00_ドキュメント規約.md)。

## 1. 実装する

| やること | 読むもの |
|---|---|
| **次に何をやるか知る／作業を再開する** | [05_実装計画と現在地](05_実装計画と現在地.md)（「次にやること」だけ読めば再開できる） |
| **会計の正しさを確かめる**（仕訳・訂正・締め・繰越） | [04_会計ドメイン設計](04_会計ドメイン設計.md) — 複式簿記の正しさはここで担保する |
| **消費税を実装する** | [06_消費税設計](06_消費税設計.md) → [消費税リサーチ](research/2026-08-23_消費税インボイス制度.md) |
| **帳簿を作る・法定検索を確かめる** | [電帳法リサーチ §3.5・§13.1](research/2026-08-23_電子帳簿保存法.md) → [取引金額での検索の調査](research/2026-08-24_仕訳の取引金額での検索.md)。帳簿は明細 1 行＝1 レコードのクエリモジュールで作る（`Designer/Design/Modules/Books/`） |
| 新しい機能を検討する | [03_機能スコープ](03_機能スコープ.md) → 該当する [ADR](decisions/README.md) |
| 「この機能は入れるのか」を判断する | [02_ペルソナ](02_ペルソナ.md) → [03_機能スコープ](03_機能スコープ.md) |
| CLB の書き方を調べる | `../Designer/CLAUDE.md` → `../Designer/ClaudeCodeForDesigner/CLAUDE.md`（仕様リファレンス） |
| CLB の制約・「静かな失敗」を避ける | [qa/01_CLB静かな失敗](qa/01_CLB静かな失敗.md) |
| **判断の経緯を知りたい** | [decisions/README](decisions/README.md)（ADR。仕様書は What、経緯はこちら） |
