## 4. 会計コアの実力 — 財務三表＋月次推移（4分）【「弥生の代替」の根拠】

「財務帳票」グループを上から順に（対象年度=第18期）。

- 合計残高試算表 → 「最下段に**貸借検算行**（11,852,675 = 11,852,675）。貸借が合わない伝票はそもそも確定できない設計です」
- 貸借対照表・損益計算書 → 「貸借対照表は**勘定式**——左に資産の部、右に負債・純資産の部が並び、**最終行で資産合計 5,868,985 と負債・純資産合計が同じ行で向かい合う**。一致していれば貸借整合が一目です。当期純利益は PL・BS・株主資本等変動・翌期期首の**4ヶ所で同じ数字**——複式簿記の一致の網です」
- **月次推移表** → PL/BS 切替 → 「BS も**全12ヶ月で貸借一致**を検算済み」
- **キャッシュ・フロー計算書** → 「財務三表が揃っています。中小向けソフトで C/F まで出るものは実は少ない。赤字172万に対して現金流出は134万——**利益と現金は別物**、が1画面で読めます」
- 資金繰り予測 → 「未回収請求・未払い・人件費から**4ヶ月先の資金**を予測。ショートする月には⚠警告がホームにも出ます」

## 5. IT受託の決め手 — 案件損益・SES・年払い（3分）【ペルソナ特化＝market gap】

> 「ここからが**受託ソフトハウスのための機能**——市販ソフトが一番弱いところです」

- 「案件/案件損益」 → 「売上も経費も人件費配賦も**案件別**に。受託 粗利55%・SaaS 12%・SES 40%——**どの案件で稼ぎ、どこで人件費を溶かしているか**が1画面です。配賦は仕訳を作らない管理会計レイヤなので帳簿は汚れません」
- 「販売/SES精算・請求」 → 「精算を計算」→ 「**精算幅（140〜180h）と超過・控除単価**で請求額を自動計算（基本80万＋超過10h=84.5万）。内訳ごと請求書になります」

- 「販売/請求書」 → 詳細の「請求書を出力（Excel/PDF）」→ 「見積書・請求書は**レイアウト帳票で1枚ずつ出力**。テンプレートは Excel ファイルなので、御社のロゴ・様式への差し替えは Excel を編集するだけです」

## 想定 Q&A

| 質問 | 答え |
|---|---|
| 請求書の PDF は？ | 見積書・請求書とも1枚ずつの帳票出力に対応（Excel/PDF・検証済み）。テンプレは Excel なので様式変更が容易 |
| スマホ対応は？ | CLB は PageFrame のデバイス出し分けに対応（本デモは PC 最適化。スマホ用フレームは追加実装） |
| 銀行 API 連携は？ | 契約・認証が必要なため CSV 取込を標準に。API は個別導入で拡張可能 |
| 電子帳簿保存法は？ | 証憑添付と検索性は実装済み。タイムスタンプ等の完全準拠は運用要件に合わせて拡張 |
| 決算期が3月でないが？ | 会計年度マスタで任意に設定可能。月次推移表なども自動追随 |
| 既存データの移行は？ | 仕訳 CSV インポート＋開始残高（期首残高画面）で移行。デモ可能 |
| 間違えて確定したら？ | 検収・入金・未払計上・支払など自動仕訳系は各画面の**赤い「〜を取り消す」ボタン**で該当仕訳ごと巻き戻せる（締め済み期間は不可）。手動の確定仕訳は編集不可（監査証跡）で、赤伝＝反対仕訳→黒伝で訂正する統制（デモデータに実例: 仕訳 No.29〜31） |
| 決算はどこまで？ | 月次締め・減価償却・経過勘定・消費税振替・法人税等・**翌期繰越（BS残高＋損益の剰余金合算）**まで。このデモデータ自体が決算完了済みの1年分 |
