# CLB マニュアル改善提案（DOC）

マニュアル・生成リファレンスへの改善提案。書式と運用ルールは [README](README.md) を参照する。

### DOC-001【中】`Creator` / `Updater` の型が、同じファイルの本文と表で食い違っている

- **発見日**: 2026-09-03
- **CLB バージョン**: ランタイム 1.3.20 / デザイナ 1.3.20 / Extras 0.5.0
- **症状**: 予約名フィールド `Creator` / `Updater` のデザイン型が、資料によって違う。
  **`LinkFieldDesign` と書いているもの**——`_specs/ModuleDesign.md` のシステムフィールド一覧、
  `Docs/AppPatterns/system_fields.md` の表、公式マニュアル `JP/fields/field.md`、
  そして `Docs/CommonMistakes.md` **#41 の予約名一覧**（`AppUser` を参照する具体例つき）。
  **`TextFieldDesign (推奨)` と書いているもの**——`Docs/CommonMistakes.md` **#42-A の表**。
  つまり**同じファイルの #41 と #42-A が食い違っている**。
  なお前回プロジェクトは 22 モジュールすべてで `LinkFieldDesign` を実運用している。
  なお `AppPatterns/system_fields.md` が案内するサンプル `SystemFieldsSample.mod.json` には
  `CreatedAt` / `UpdatedAt` しか無く、`Creator` / `Updater` の実例が無い。
- **なぜ困るか**: 予約名は**型が合っていて初めて自動セットが効く**（#42-A の本文がそう述べている）。
  表を信じて `TextFieldDesign` にすると、`designcheck` は通るのに値が入らない。
  **本プロジェクトは表を信じて自前の静的検査にも `TextFieldDesign` を焼き込んでいた**
  （2026-09-03 に直した）。**まだ実機では確かめていない。**
- **提案**: #42-A の表を `LinkFieldDesign` に直す。あわせて `SystemFieldsSample` に
  `Creator` / `Updater` の実例（`ValueVariable` / `DisplayTextVariable` つき）を足す。
  **#34（自前の作成者欄を `TextFieldDesign` ＋ `IgnoreModification` で作る話）と
  取り違えやすい**ので、両者を相互に参照させるとよい。
- **回避策**: `AppPatterns/` を正典として `LinkFieldDesign` を採る（CLAUDE.md §3-2 の方針）。
- **出典**: [qa/01 F-09](../qa/01_CLB静かな失敗.md)（訂正の経緯）

### DOC-002【低】`LinkFieldNames` の書式が、`designcheck` でも実行時でも検証されない

- **発見日**: 2026-09-03
- **CLB バージョン**: ランタイム 1.3.20 / デザイナ 1.3.20 / Extras 0.5.0
- **症状**: `LinkFieldNames` の書式は `"{LinkField の名前}.{参照先のフィールド名}"` と説明されているが
  （`_specs/ModuleDesign.md`・`Docs/CommonMistakes.md` #20）、**`_samples` には裸の名前だけを書いた
  エントリが 5 件ある**（15 モジュール・28 エントリ中。どれも子 `ListField` の名前）。
  **裸の名前が有効なのか無視されるのかが、資料からもサンプルからも読み取れない。**
  どちらであっても `designcheck` は通る。
- **なぜ困るか**: 「足したのに効いていない」のか「これで正しい」のかが分からない。
  本プロジェクトは 5 モジュールで裸の名前を書いている（`DisplayTextVariable` が別経路で解くので
  実害は出ていないが、**効いているかどうかを確かめる手段が無い**）。
- **提案**: **裸の名前が有効かを資料で明示する。** 無効なら `designcheck` が
  「要素に `.` が無い」「左辺が LinkField でない」「右辺が参照先に無い」を報告し、
  `_samples` の 5 件も直す。有効なら書式の説明にその形を足す。
- **回避策**: いまは無い。**直すのは実機で見られる回**（[qa/01 F-35](../qa/01_CLB静かな失敗.md)）——書式を直すと表示の解決に影響しうるので、目で見られないうちは動かさない。
- **出典**: [qa/01 F-35](../qa/01_CLB静かな失敗.md)
