# 機能スコープ

> **含める／含めないの正典。** 判断の理由は [ADR-0007](decisions/0007-会計コアの機能スコープ.md)、
> 実装の順序は [05_実装計画と進捗台帳](05_実装計画と進捗台帳.md) にある（ここには書かない）。
> 基準は 1 つだけ:「[対象ペルソナ](02_ペルソナ.md)が使うか」。

凡例: ○ = 会計コアに含める ／ △ = 連携点だけ持つ ／ × = 含めない（別部品または対象外）

## A. マスタ・設定

制度ルール／会計設定／会計マスタの 3 層に分ける（[ADR-0006](decisions/0006-マスタの三層分類.md)）。

| | 機能 | 層 | 備考 |
|---|---|---|---|
| ○ | 事業所情報（法人名・住所・登録番号・決算期） | 会計設定 | 1 レコード（[ADR-0005](decisions/0005-単一法人に徹する.md)） |
| ○ | 会計年度・会計期間（月次）と締め状態 | 会計設定 | 状態を持つ台帳 |
| ○ | 消費税設定（課税方式・経理方式・控除方式） | 会計設定 | 課税期間単位で持つ |
| ○ | 期首残高（開始残高） | データ | 貸借一致の検証対象 |
| ○ | 勘定科目（科目区分・決算書表示区分・既定税区分） | 会計マスタ | |
| ○ | 補助科目 | 会計マスタ | 科目配下の内訳 |
| ○ | 取引先（登録番号・適格請求書発行事業者か・有効期間） | 会計マスタ | 経過措置の判定に必須 |
| ○ | 部門 | 会計マスタ | 単一階層（[ADR-0010](decisions/0010-部門は単一階層とし損益科目でのみ必須にする.md)） |
| ○ | 税区分（課税/非課税/不課税/免税・税率・用途区分） | 会計マスタ ＋ 制度ルール | 割当はマスタ、税率は制度ルール |
| ○ | 消費税率・経過措置の控除割合・相手方別上限額 | 制度ルール | 有効期間付き。利用者は編集できない |
| ○ | 法定耐用年数・償却率 | 制度ルール | 同上 |
| × | ユーザー・権限・ロール | — | 認証部品の責務。既存の `AppUser` を使う |
| × | セグメント・タグ（部門以外の集計軸） | — | 管理会計部品 |

## B. 記帳（仕訳の生成と保全）

| | 機能 | 備考 |
|---|---|---|
| ○ | 仕訳入力（複合仕訳・諸口） | 振替伝票形式 |
| ○ | 出納帳形式の入力 | 現金・預金の連続入力 |
| ○ | 下書き（draft）と計上（posted）の分離 | 下書きは自由に編集・削除できる |
| ○ | 仕訳番号の自動採番（不可逆） | 訂正削除履歴と相互関連性の前提 |
| ○ | **訂正・取消（反対仕訳方式）** | 計上済みは変更・削除しない（[ADR-0004](decisions/0004-優良な電子帳簿への準拠と仕訳の不変性.md)） |
| ○ | 入力年月日の自動付与（訂正・削除不可） | 優良な電子帳簿の要件 |
| ○ | 通常の業務処理期間の経過後の入力の記録 | 同上 |
| ○ | 仕訳の検証（貸借一致・期間・科目・税区分・部門） | `AccountingCore` で実装しサーバで強制 |
| ○ | 月次締め・年度締め・期間ロック | 締め前チェックを含む |
| ○ | 締めの再オープン（理由の記録つき） | |
| ○ | CSV による仕訳の取込 | 冪等性・Dry-run・行単位エラー |
| △ | 他部品からの仕訳投入 | 元伝票を特定する情報を保持する |
| △ | 証憑との紐付け | 参照キーのみ。実体は証憑部品 |
| × | 仕訳辞書・定型仕訳・自動仕訳ルール | 入力支援。会計の責務ではない |
| × | 銀行・カード明細の取込、OCR、AI 仕訳提案 | 入力支援部品 |
| × | 承認ワークフロー | 承認フロー部品 |

## D. 消費税

| | 機能 | 備考 |
|---|---|---|
| ○ | 税抜経理（仮払・仮受消費税等の自動計上） | ペルソナは税抜経理 |
| ○ | 税率別集計（複数税率・経過措置税率） | |
| ○ | 売上税額の計算（割戻し・積上げ） | 組み合わせ制約を強制する |
| ○ | 仕入税額の計算（積上げ・割戻し） | 同上 |
| ○ | 税率ごとに 1 回の端数処理 | 行ごとに切り捨てない |
| ○ | 課税売上割合の計算 | 切り捨て表示 |
| ○ | 全額控除・個別対応方式・一括比例配分方式 | 課税期間ごとに選べる |
| ○ | 用途区分（課税売上対応／共通対応／非課税売上対応） | 個別対応方式に必須 |
| ○ | 免税事業者等からの仕入れの経過措置 | 日付で控除割合を自動切替 |
| ○ | 相手方別の課税仕入れ累計と上限判定（税込 1 億円） | 2026-10-01 以後に開始する課税期間から |
| ○ | 帳簿のみ保存で控除できる類型の区分と追加記載事項 | ペルソナが使う 5 類型のみ（下記） |
| × | **少額特例**（税込 1 万円未満） | **ペルソナは適用対象外**。基準期間の課税売上高 1 億円超かつ特定期間 5,000 万円超 |
| ○ | 税額の手動上書き（履歴を残す） | 積上げ計算のズレを吸収する |
| ○ | 税区分別集計表（申告の根拠） | 取引まで追跡できる |
| × | 簡易課税 | ペルソナは本則課税 |
| × | 2 割特例・3 割特例 | 同上 |
| × | 税込経理 | ペルソナは税抜経理 |
| × | 消費税申告書・付表の様式出力、中間申告 | 申告は税理士が行う |

**帳簿のみ保存で控除できる類型**は、ペルソナが実際に行う次の 5 つだけを持つ。
①3 万円未満の公共交通機関 ②入場券等の回収特例 ③3 万円未満の自動販売機・自動サービス機
④郵便ポストに差し出された郵便・貨物サービス ⑤従業員等への出張旅費・宿泊費・日当・通勤手当。
古物商・質屋・宅地建物取引業・特定金属くず・再生資源の各特例は業種特有のため持たない
（区分をマスタとして持つので、必要になれば行を足せる）。

## F. 保存・統制・外部連携

| | 機能 | 備考 |
|---|---|---|
| ○ | 監査ログ（操作・閲覧・出力） | 利用者による改ざんを防ぐ |
| ○ | 法定保存期間を通じた保持と再現 | 会社法 10 年が実効的な制約 |
| ○ | **完全なエクスポート**（仕訳・マスタ・残高・設定・履歴・データ辞書） | 出口を塞がない |
| ○ | システム関係書類（概要書・操作説明書） | 優良な電子帳簿の要件 |
| △ | 他部品向けの仕訳投入 API | 冪等性キーを持つ |
| × | e-Tax / eLTAX 連携・XBRL | 申告者の提出行為 |
| × | 税理士アカウント・共同作業機能 | 認証部品 ＋ 製品化フェーズ |
| × | 他社会計ソフトからの移行ツール | 製品化フェーズ（CSV 取込で代替する） |
