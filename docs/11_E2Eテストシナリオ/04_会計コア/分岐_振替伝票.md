## ブロック系（JRN-01〜04）

### JRN-01: 明細 0 行で確定 → ブロック
- **操作手順**: 新規作成 → 取引日 2026-07-15・摘要「JRN-01」だけ入れて明細を**追加せず**「確定」。
- **期待される結果**: トースト「**明細を 1 行以上入力してください**」。伝票は保存されない（URL が `/-` のまま）。
- **確認ポイント**: 「下書き保存」でも同じブロックが働く（保存経路共通の検証）。

### JRN-02: 金額 空・0・マイナス → ブロック
- **操作手順**: 明細 1 行（借方・消耗品費）を追加し、金額を (a) 空のまま (b) 0 (c) -100 の 3 通りで「確定」。
- **期待される結果**: いずれも トースト「**明細の金額は 1 円以上で入力してください**」（コード上 `Amount == null || Amount <= 0` の同一判定）。
- **確認ポイント**: マイナス入力で赤伝を作る運用は**できない**——取消は貸借を逆にした正の金額で行う（07_特殊取引の赤黒訂正が正規ルート）。

### JRN-03: 勘定科目 未選択 → ブロック
- **操作手順**: 明細 1 行に金額 1,000 だけ入れ（科目は空）「確定」。
- **期待される結果**: トースト「**明細の勘定科目を選択してください**」。
- **確認ポイント**: 科目を選んだ瞬間に税区分・税入力（内税）が自動セットされる（ApplyLineDefaults）——ブロック解消と同時に既定値が入ることを見る。

### JRN-04: 取引日の 3 ガード（年度なし・期間なし・締め済み）
- **操作手順**（明細は 借方 消耗品費 1,000／貸方 現金 1,000 の一致状態で）:
  1. 取引日「**2024-06-15**」（年度が存在しない過去）→「確定」→ 日付欄に「**取引日に対応する会計年度がありません**」。
  2. 取引日「**2026-04-15**」（締め済みの月次 1）→「確定」→「**締め済みの期間には起票できません**」。
  3. 【期間なしの構成】【会計】設定/会計年度 > 新規作成で「第20期」（期首 2028-04-01・期末 2029-03-31）を**月次期間を生成せずに**登録 → 振替伝票で取引日「**2028-06-15**」→「確定」→「**取引日に対応する月次期間がありません**」（年度はあるが期間が無い状態）。
- **期待される結果**: 3 種のメッセージがすべて**日付欄のフィールドエラー**として出る（トーストではない）。伝票は一切保存されない。
- **後片付け**: 第20期を一覧から削除。伝票画面は保存せず離脱。
- **実務解説**: 「年度なし」と「期間なし」は区別されている——移行初年度に期間生成を忘れた事故を、締めガードと違うメッセージで検知できる。

## 貸借一致と下書きの順路（JRN-05〜06）— 2026-07-10 修正の回帰確認

### JRN-05: 貸借不一致 → 明細が入力状態に自動復元 → 差額が毎回同じ
- **この分岐の目的**: 旧バグ「確定失敗後に再確定すると税抜化が二重適用され差額が変わっていく」が直っていることの回帰確認（コード: RestoreInputState）。
- **操作手順**:
  1. 新規作成: 取引日 2026-07-15・明細 1「借方 消耗品費 **7,700**（内税自動）」・明細 2「貸方 現金 **7,000**」（わざと不一致）。
  2. 「確定」→ トースト「**貸借が一致していません（差額 700 円）**」。
  3. 明細を見る: **2 行のまま・金額 7,700／7,000 の入力値が保たれている**（税行が残っていない・7,000 が 6,364 に化けていない）。
  4. **何も直さずもう一度「確定」** → 再び「差額 **700** 円」——**差額が前回と同じ**であること（旧バグでは 2 回目に -1,336 など別の値になった）。
  5. 保存せず離脱（または明細 2 を 7,700 に直して下書き保存 → 一覧から削除）。
- **期待される結果**: 上記のとおり。差額の計算は税行込み（7,700 = 7,000+700 vs 7,000）で行われ、失敗のたびに入力状態へ巻き戻る。
- **帳簿への影響**: なし。

### JRN-06: 下書きは「生の入力」のまま保存される
- **操作手順**:
  1. 新規作成: 取引日 2026-07-15・借方 消耗品費 **11,000**（内税）／貸方 現金 11,000 →「**下書き保存**」→「下書きを保存しました」（伝票番号なし）。
  2. 一覧に戻り、この下書きを開き直す。
- **期待される結果**: 明細は **2 行のまま・金額 11,000／11,000**（税行が無い・税抜化されていない）。下書き段階では税分解が起きないことの実証（税行は確定時に生成——基本 4-1 で確認済み）。
- **後片付け**: この下書きを一覧から**削除**。
- **補足**: 旧仕様（〜2026-07-09）で保存された「税抜変換済み・税行あり」の下書きが残っていた場合は、開いた瞬間に入力状態へ復元表示される（互換処理。新規 DB では発生しない）。

## 税行が立たない条件（JRN-07）

### JRN-07: 税入力「なし」・非課税・対象外 → 税行なしの 2 行伝票
- **操作手順**（確定はしない——明細を組んで「確定」直前まで。挙動自体は基本 4-4（不課税・給与）/4-5（非課税・保険料）/7-6（対象外・貸倒損失）で確定済み伝票として実証済み）:
  1. 借方 地代家賃（課税仕入・内税が自動セット）→ 税入力を「**なし**」に手動変更。
  2. 借方行を 保険料（非課税仕入）・雑費→税区分を「対象外」に変えた場合も、確定時に税行が生成されないことを既存伝票（No.18/19/33）の明細で突合する。
- **期待される結果**: 税行が立たない 4 条件（税区分なし／税入力なし／税率 0／課税売上・課税仕入以外）がコードどおりであること。
- **帳簿への影響**: なし（確認は既存伝票の参照で行う）。

### JRN-08: 内税の端数切り捨て（10,000 → 税 909）
- **操作手順**: 取引日 2026-07-15・借方 消耗品費 **10,000**（内税）／貸方 現金 10,000 → 確定。
- **期待される結果**: 明細 3 行 = 消耗品費 **9,091**／現金 10,000／仮払消費税 **909**（10,000×10/110 = 909.09… → **切り捨て**。差額 1 円は本体側に寄る）。
- **後片付け**: 同日付で赤伝（貸方 消耗品費 10,000 内税／借方 現金 10,000）を切ると残高が戻る。

### JRN-09: 外税の端数切り捨て（555 → 税 55）
- **操作手順**: 借方 広告宣伝費・税入力「**外税**」・金額 **555**／貸方 未払金 **610** → 確定。
- **期待される結果**: 明細 3 行 = 広告宣伝費 555／未払金 610／仮払消費税 **55**（555×10% = 55.5 → 切り捨て。借方計 610 = 貸方計 610）。
- **確認ポイント**: 外税は本体がそのまま残り税が上乗せされる（内税と起点が逆）。貸方は**税込 610** で入力しないと不一致ブロックになる。

### JRN-10: インボイス経過措置の日付跨ぎ（80% → 70%）
- **この分岐の目的**: 控除割合が**マスタの期間解決だけで**切り替わることの実証（2026-09-30 まで 80%／2026-10-01 から 70%。ddl/010 の invoice_transition_rates）。制度改正への追随がコード変更ゼロであることが売り。
- **前提**: 月次 6（2026-09）・月次 7（2026-10）を進行中に戻す。
- **操作手順**:
  1. 取引日「**2026-09-20**」・借方 消耗品費・税区分「**課税仕入 10%(経過措置)**」・内税 **11,000**／貸方 現金 11,000 → 確定。
  2. 取引日「**2026-10-01**」で同じ内容をもう 1 枚 → 確定。
- **期待される結果**:
  - 9/20 分: 本体 **10,200**＋仮払消費税 **800**（1,000×80%。基本 4-8 と同じ）。
  - 10/1 分: 本体 **10,300**＋仮払消費税 **700**（1,000×**70%**）——**境界日 10/1 ちょうどで新割合**（ValidFrom 以上判定）。
- **後片付け**: 各日付で赤伝 2 枚。月次 6・7 を締め直す。
