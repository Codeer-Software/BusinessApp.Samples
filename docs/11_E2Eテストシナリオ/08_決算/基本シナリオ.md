# 08_決算 基本シナリオ（締め・減価償却・経過勘定・消費税・繰越）

> 改訂: 2026-07-10（ページフレーム分割・組織再編・sysadmin ロールに追随。金額・仕訳番号は不変）
>
> **実務上の位置づけ**: 決算とは「期間の損益を確定させる」作業。日常の記帳（01〜07 の各章）は取引の都度行うが、**時の経過によって発生する費用**（減価償却・前払費用の按分）や**期末にしか確定しない負債**（未払消費税・法人税）は決算整理仕訳としてまとめて計上する。月次では「締め」（その月への遡及起票の禁止）で数字を凍結し、年次では決算整理 → 翌期への繰越で 1 年を閉じる。
>
> 本章の順序: ①月次締めの動作確認 → ②締め済み期間に絡む経費のフォールバック → ③減価償却 → ④前払費用 → ⑤消費税の振替 → ⑥法人税等 → ⑦全期間の締め → ⑧第 19 期の作成と繰越 → ⑨年度クローズ。
>
> **使用ユーザー**: soumu_bucho（総務部 部長 山田太郎・経理）。8-2 のみ kaihatsu1_ippan・kaihatsu1_kacho1 が登場。

### ステップ 8-1: 月次締め（6 月を締める）と下書き残存警告

- **この業務の目的（実務解説）**: 月次決算の完了宣言。締めた月には新規・修正の仕訳を入れられなくなり、月次報告の数字が動かなくなる。締める前に「処理し忘れの下書き」が無いかをシステムが警告してくれる。
- **操作する画面**: 【会計】仕訳/振替伝票／【会計】設定/会計年度 > 第18期
- **具体的な操作手順**:
  1. 【警告デモの仕込み】振替伝票 → 新規作成: 取引日「2026-06-15」・借方 消耗品費 1,000／貸方 現金 1,000 →「**下書き保存**」（確定しない）。
  2. 【会計】設定/会計年度 > 第18期 を開き、月次期間リストの**月次 3（2026-06）**の状態を「締め済み」に変更する → その場でトースト「**この期間には下書きの伝票が 1 件残っています。締める前に確定または削除を検討してください（保存すると締めは実行されます）**」（警告のみ・ブロックしない）。
  3. **保存せず**に状態を「進行中」へ戻し、振替伝票一覧から手順 1 の下書きを削除する。
  4. 改めて月次 3 を「締め済み」に変更（今度は警告なし）→「登録」で保存。
  5. 【締めの効力確認】振替伝票 → 新規作成: 取引日「2026-06-20」・適当な明細で「確定」→ 赤トースト「**締め済みの期間には起票できません**」。保存せず破棄する。
- **期待される結果**:
  - **直接的な結果**: 6 月が締まり、6 月日付の起票が全経路で拒否されるようになる（振替伝票だけでなく検収・入金・経費・銀行取込・インポートも同じガードを通る）。
  - **波及する結果**: 6 月の確定済み仕訳（No.6 外注費）はそのまま帳票に載り続ける（締めは「凍結」であって「削除」ではない）。締め解除（進行中に戻す）も経理ならいつでも可能。

### ステップ 8-2: 締め済み期間の経費申請 E-5 —— 自動フォールバック（仕訳 No.36・37）

- **この業務の目的（実務解説）**: 「4 月のタクシー領収書が今頃（7 月）出てきた」——締めた月の経費は実務で必ず発生する。過去の月次を開け直すのは大ごとなので、**重要性の乏しい少額経費は処理日（今日）の日付で計上し、摘要に本来の利用日を記録する**のが実務の定石。本アプリはこれを自動で行う。
- **操作する画面**: （kaihatsu1_ippan）ホームのショートカット「経費申請」（経費一覧） →（kaihatsu1_kacho1）承認 →（soumu_bucho）経理処理
- **具体的な操作手順**:
  1. kaihatsu1_ippan（開発1部 一般 小林美咲）で経費申請: 件名「タクシー代（4月分・精算遅れ）」・金額（税込）「3,300」・費目「旅費交通費」・**利用日「2026-04-10」**（締め済みの 4 月）・利用先「日本交通」→「申請」（3,300 円 < 3 万 → 課長ルート）。
  2. kaihatsu1_kacho1（開発1部 第一課長 山本由美）で承認。
  3. soumu_bucho（総務部 部長 山田太郎）で申請を開き「仕訳を生成」。
- **期待される結果**:
  - **直接的な結果**: 情報トースト「**利用日（2026/04/10）の期間が締め済みのため、本日（2026/07/31）日付で起票しました（摘要に利用日を記載）**」＋「仕訳 No.36 を生成しました（借方 旅費交通費 3,000 円 / 貸方 未払金 3,300 円）」。仕訳の摘要は「経費精算 タクシー代（4月分・精算遅れ）（利用日 2026/04/10）」。
  - **続けて**「精算済にする」→ 支払仕訳 No.37 →「完了にする」。
  - **波及する結果**: 月次推移表では 4 月ではなく**7 月（起票月）の費用**として載る（締めた 4 月の数字は動かない——これがフォールバックの目的）。予実対比の旅費交通費実績が 47,364 に増える。年度をまたぐ場合（前年度の利用日）はさらに「当期の費用として計上します。金額が重要な場合は決算修正をご検討ください」という警告に変わる。

### ステップ 8-3: 減価償却費の計上（仕訳 No.38）

- **この業務の目的（実務解説）**: 01_経費精算 で買ったワークステーション 150,000 円（税抜）は、買った月の費用ではなく**耐用年数にわたって配分**する（減価償却）。パソコン類の法定耐用年数は 4 年・定額法が標準。年額 = 150,000 ÷ 4 = 37,500、当期は 7 月取得なので**月割 9 ヶ月分（7 月〜3 月）= 28,125 円**。本アプリは直接法（貸方を資産科目から直接減らす）で自動起票する。
- **操作する画面**: 【会計】仕訳/固定資産台帳
- **具体的な操作手順**:
  1. 【会計】仕訳/固定資産台帳 を開き、01_経費精算 で自動登録された「EXP-xx 開発用ワークステーション」を開く。
  2. 内容確認: 取得日 2026-07-14・取得価額 150,000（税抜）・償却方法「定額法」（自動登録時の仮設定）・部門 開発1部。**少額判定**欄に「取得価額 150,000 円 < 200,000 円: 一括償却資産（3年均等）を選択できます」のヒントが出ている（今回は原則どおり定額法を採用）。
  3. **耐用年数「4」**（年）を入力して「登録」。
  4. 対象年度「第18期」を選択し「**この年度の償却仕訳を生成**」を押す。
  5. 【二重生成ガード】もう一度押す → 「この年度の償却仕訳は既に生成済みです」。
- **期待される結果**:
  - **直接的な結果**: トースト「**償却仕訳 No.38（28,125 円）を生成しました**」。
  - **波及する結果**:
    - **仕訳帳**: No.38／**2027-03-31（期末日）**／借方 減価償却費 28,125（部門: 開発1部）／貸方 工具器具備品 28,125。
    - **試算表**: 工具器具備品の残高 **121,875**（150,000 − 28,125）＝帳簿価額。
    - **損益計算書**: 減価償却費 28,125。**キャッシュ・フロー計算書**（09_帳票検証）では「非資金費用」として営業 CF に足し戻される——お金が出ていかない費用の代表例。
    - **予実対比**: 開発1部に減価償却費の実績が付く（部門引継ぎ）。

### ステップ 8-4: 前払費用の振替（仕訳 No.39）

- **この業務の目的（実務解説）**: 7/1 に年払いした保険料 66,000 円（2026-07〜2027-06 の 12 ヶ月分）のうち、**翌期分の 3 ヶ月（2027-04〜06）= 16,500 円は当期の費用ではない**。期末にその分を費用から抜いて「前払費用」（資産）へ振り替える——経過勘定の代表例（費用収益対応の原則）。
- **操作する画面**: 【会計】仕訳/振替伝票 > 新規作成
- **具体的な操作手順**:
  1. 新規作成: 取引日「2027-03-31」・伝票種別「**決算整理**」・摘要「保険料の前払振替（2027-04〜06 分 3 ヶ月）」。
  2. 明細 1: 借方「前払費用」16,500（税計算なし）。
  3. 明細 2: 貸方「保険料」16,500 — 科目選択で税区分「非課税仕入」が自動セットされるが、決算振替に税は絡まないため税入力を「なし」に変更 → 「確定」。
- **期待される結果**:
  - **直接的な結果**: 「伝票 No.39 を確定しました」（2 行）。
  - **波及する結果**: 損益計算書の保険料が **49,500**（66,000 − 16,500 = 当期 9 ヶ月分）に補正され、BS の資産に前払費用 16,500 が立つ。翌期首にはこの逆仕訳（借方 保険料／貸方 前払費用）を切って費用化する（第 19 期の作業なので本書では行わない）。

### ステップ 8-5: 消費税の期末振替（仕訳 No.40）

- **この業務の目的（実務解説）**: 期中に積み上げた「仮受消費税（顧客から預かった税）」と「仮払消費税（支払時に負担した税）」を期末に相殺し、差額を**未払消費税等（納税義務）**として確定する。税抜経理の締めくくり。
- **操作する画面**: 【会計】帳票/合計残高試算表 → 【会計】仕訳/振替伝票
- **具体的な操作手順**:
  1. まず【会計】帳票/合計残高試算表（日付 2026-04-01〜2027-03-31）で 2 科目の**残高**を確認: 仮受消費税 **344,500**／仮払消費税 **103,289**。
     （参考: 【会計】帳票/消費税集計表 で税区分別の内訳も見られるが、赤黒訂正の両建てを含む単純合計のため、振替額は必ず**残高**で取ること——07_特殊取引 7-2 の注記参照。）
  2. 振替伝票 → 新規作成: 取引日「2027-03-31」・伝票種別「決算整理」・摘要「消費税の期末振替」。
  3. 明細（3 行。各行とも税入力「なし」）:
     - 借方「仮受消費税」344,500
     - 貸方「仮払消費税」103,289
     - 貸方「未払消費税等」**241,211**
  4. 借方合計 344,500 ＝ 貸方合計 344,500 を確認して「確定」。
- **期待される結果**:
  - **直接的な結果**: 「伝票 No.40 を確定しました」。
  - **波及する結果**: 試算表で仮受消費税・仮払消費税の残高が **0** になり、未払消費税等 **241,211** が立つ。BS の負債に「未払消費税等 241,211」——これが翌期に納付する消費税額（実際の申告計算では中間納付・端数処理等の調整があるが、本アプリの帳簿レベルではこの振替で完結）。

### ステップ 8-6: 法人税等の計上（仕訳 No.41）

- **この業務の目的（実務解説）**: 当期は**税引前で赤字**（△1,727,226 円）なので利益に対する法人税は発生しないが、**住民税の均等割**（資本金等に応じた固定額。中小なら年 7 万円程度）は赤字でも必ずかかる——「赤字でも税金ゼロではない」は実務の重要知識。
- **操作する画面**: 【会計】仕訳/振替伝票 > 新規作成
- **具体的な操作手順**:
  1. 新規作成: 取引日「2027-03-31」・伝票種別「決算整理」・摘要「法人税等の計上（住民税均等割）」。
  2. 借方「法人税、住民税及び事業税」70,000／貸方「未払法人税等」70,000（税計算なし）→ 確定。
- **期待される結果**:
  - **直接的な結果**: 「伝票 No.41 を確定しました」。**これで第 18 期の全 41 仕訳が出揃った**。
  - **波及する結果**: 損益計算書の最終行が確定する: 税引前当期純利益 **△1,727,226** − 法人税等 70,000 = **当期純利益 △1,797,226**。BS 負債に未払法人税等 70,000。

### ステップ 8-9: 翌期繰越の実行（BS 残高＋当期純利益の引き継ぎ）

- **この業務の目的（実務解説）**: 年次決算の総仕上げ。**BS 科目（資産・負債・純資産）の期末残高を翌期の期首残高にコピー**し、**当期純損益は繰越利益剰余金に合算**する（PL 科目は翌期ゼロから再スタート）。本アプリは損益振替仕訳を作らず、繰越時に純利益を直接 3100 に加算する方式。
- **操作する画面**: 【会計】設定/会計年度 > 第18期
- **具体的な操作手順**:
  1. 第18期を開き「**翌期繰越を実行**」を押す。
  2. 確認ダイアログ「第19期 の期首残高を作成します（既存の期首残高は洗い替えされます）。よろしいですか？」→「実行」。
- **期待される結果**:
  - **直接的な結果**: トースト「**第19期 への繰越が完了しました**」。
  - **波及する結果**: 第19期を開くと期首残高に **14 行**が生成され、「期首残高合計」= **0**（貸借一致）:
    | 科目 | 期首残高（借方正） |
    |---|---|
    | 現金 | 74,700 |
    | 小口現金 | 80,000 |
    | 普通預金 | 3,655,910 |
    | 売掛金 | 1,320,000 |
    | 前払費用 | 16,500 |
    | 工具器具備品 | 121,875 |
    | 敷金保証金 | 600,000 |
    | 未払金 | -55,000 |
    | 預り金 | -450,000 |
    | 前受収益 | -1,100,000 |
    | 未払消費税等 | -241,211 |
    | 未払法人税等 | -70,000 |
    | 資本金 | -5,000,000 |
    | 繰越利益剰余金 | **+1,047,226** |
    - 繰越利益剰余金が**借方残（正の値）**になっている点に注目: 期首 △750,000（貸方残）＋当期純損失 1,797,226 ＝ 累積 1,047,226 円の**欠損**。赤字を出すと剰余金が食い潰される様子が符号で見える。
    - 各値は第18期 BS の期末残高（09_帳票検証 で突合する）と完全一致する。
    - 繰越は**洗い替え式**なので、繰越後に第18期の仕訳を追加・修正した場合はもう一度実行すれば期首残高が作り直される（冪等）。

### ステップ 8-10: 年度のクローズ

- **操作する画面**: 【会計】設定/会計年度 > 第18期
