## 償却仕訳生成のガード順序（仕様の正: `FixedAsset.mod.cs` GenerateDep_OnClick）

上から順に判定される。**先に当たったガードのメッセージだけが出る**——完成状態 DB で第18期を選ぶと常に①が出る点に注意:

| # | ガード | メッセージ |
|---|---|---|
| 0 | 未保存／対象年度未選択 | 「資産を保存してから実行してください」／「対象年度を選択してください」 |
| ① | 対象**年度**が締め済み | 「締め済みの年度には生成できません」 |
| ② | 期末**月の期間**が締め済み | 「期末月の期間が締め済みです。期間を再オープンしてから生成してください」 |
| ③ | 同一資産×同一年度の生成済み | 「この年度の償却仕訳は既に生成済みです」 |
| ④ | 償却額 0（対象外・耐用年数未設定・償却済み） | 「この年度の償却額はありません（対象外または償却済み）」（情報トースト・仕訳なし） |

## 実行上の注意（完成状態を壊さない）

現在の DB は第18期クローズ＋第19期繰越済みの完成状態。分岐はこの状態を**最終的に元へ戻す**ことを前提に設計してある:

- 年度・期間を再オープンした分岐は、末尾で**必ず締め直す／クローズし直す**。
- 繰越の再実行（CLS-07）は洗い替えで**同一の 14 行**を作り直すため、実行しても状態は変わらない（それ自体が冪等の実証）。
- 第19期に仕訳を作る操作（償却の実生成など）は**行わない**——第19期は「期首残高のみ・仕訳ゼロ」が正。
