# E2E テストシナリオ兼 業務理解ドキュメント

> 作成: 2026-07-09 ／ 対象: 本財務会計アプリの全機能
> **目的**: 財務会計の知識が乏しい開発者が、本書に沿ってアプリを操作することで、①「どの画面で何を操作すると、どの帳票・データにどう影響するか」（システムの挙動）と、②「実務では何のために・どの順番で・何の業務を行うか」（会計実務の基本）を同時に理解する。

## 1. 本書の構成（読む順序 = 実行する順序）

会計の 1 年は「**期首の準備 → 日常取引の記帳 → 月次の照合 → 決算 → 翌期への繰越**」というサイクルで回る。本書の章立てはこのライフサイクルに沿っており、**01 から 10 まで順に実行すると、まっさらな会計帳簿が 1 期分の決算を終えて翌期に繰り越されるまでの全過程**を体験できる。

## 3. 複式簿記の 30 秒サマリ（本書を読むための最低知識）

- すべての取引は「**借方（左）＝貸方（右）**」の 2 面で記録する（複式簿記）。例: 現金 7,700 円で消耗品を買う → 借方: 消耗品費 7,700／貸方: 現金 7,700。**借方合計と貸方合計は必ず一致**し、一致しない伝票はこのアプリでは「確定」できない。
- 科目には 5 区分ある: **資産**（現金・売掛金…借方が増加）／**負債**（買掛金・未払金…貸方が増加）／**純資産**（資本金）／**収益**（売上高…貸方が増加）／**費用**（給料・家賃…借方が増加）。
- 帳票はすべて仕訳の集計にすぎない: 仕訳を日付順に並べたのが**仕訳帳**、科目ごとに並べ替えたのが**総勘定元帳**、科目ごとの合計・残高一覧が**試算表（TB）**、資産・負債・純資産の残高一覧が**貸借対照表（BS）**、収益・費用の集計が**損益計算書（PL）**。**本アプリも「確定済み仕訳（posted）の集計のみ」から全帳票を導出する**ため、仕訳さえ正しければ帳票は常に整合する。
- 消費税は**税抜経理・明示税行方式**: 税込 11,000 円の課税仕入を入力すると、システムが「本体 10,000（費用）＋仮払消費税 1,000（資産）」に自動分解して別行を起こす。売上側は仮受消費税（負債）。期末に両者を相殺して納税額（未払消費税等）を確定する（第 09 章）。

**株式会社アルタイルシステムズ**（IT 受託ソフトハウス、3 月決算、第 18 期 = 2026-04〜2027-03。ペルソナの詳細は `docs/02_ペルソナ.md`）が、この会計アプリを 7 月に導入する:

## 5. テスト完了後の総合検算（sql CLI）

10 章まで完了したら、以下の検算クエリで複式簿記の健全性を最終確認する（`AccountingApp.Designer.exe sql --datasource AccountingSQLite`）:

```sql
-- ① 全確定仕訳の貸借一致（期待値: 借方=貸方=11,852,675）
SELECT SUM(CASE WHEN dc='D' THEN jl.amount ELSE 0 END) AS 借方,
       SUM(CASE WHEN dc='C' THEN jl.amount ELSE 0 END) AS 貸方
FROM journal_lines jl JOIN journal_entries je ON je.id=jl.journal_entry_id
WHERE je.status='posted';

-- ② 伝票番号の重複ゼロ（期待値: 0）
SELECT COUNT(*) FROM (SELECT fiscal_year_id, journal_no, COUNT(*) c
FROM journal_entries GROUP BY fiscal_year_id, journal_no HAVING c > 1);

-- ③ 売掛金の元帳残高 = 未回収請求の残額（期待値: どちらも 1,320,000）
SELECT (SELECT SUM(CASE WHEN dc='D' THEN amount ELSE -amount END)
        FROM journal_lines jl JOIN journal_entries je ON je.id=jl.journal_entry_id
        JOIN accounts a ON a.id=jl.account_id
        WHERE a.code='1100' AND je.status='posted') AS 売掛金元帳残高;

-- ④ 第19期 期首残高の貸借一致（期待値: 0）
SELECT SUM(balance) FROM opening_balances
WHERE fiscal_year_id=(SELECT id FROM fiscal_years WHERE name='第19期');
```
