## 3. 番号の振り方

**ここは記号（`L-nn`・`F-nn`・`R-nn` など）の番号の話である。**
`docs/` 直下の**文書番号**は十の位がカテゴリを表し、
**役割が変われば動く**（[00 §8-1](00_ドキュメント規約/README.md)）。規則が違うので混ぜないこと。

- **一度どこかから指された番号は動かさない。** 新しい体系を起こすときに**空き番から始める**ことはある
  （実例: qa/04 の登録番号の台本は R-20 から始めた——R-07〜R-13 を §4 の記録が別の意味で使っていたため）
- **欠番は正常**。`削除` を置いた欠番は経緯として正しい（[00 §4-12](00_ドキュメント規約/本文.md)）
- **新しい記号を作るときは、ここに 1 行足す。** 足さないと、半年後に読む人が引けない
