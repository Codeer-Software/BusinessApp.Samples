# （廃止）体験シナリオ: 経費精算の一巡

> **2026-08-09 廃止。** 後継は **[`20_体験シナリオ/01_経費精算/`](20_体験シナリオ/01_経費精算/)**（全 11 本）です。

本書は 2026-07-20 に作成した「開発2部 松本結衣の濃い 1 週間」の台本でしたが、その後の
ADR-0042〜0048 により**承認ルートの期待値そのものが変わり**、現行アプリと合わなくなりました。
とくに次の 2 点が本書の前提を崩しています。

- **ADR-0044（部課階層と walk-up）**: 課長決裁は「部内の全課長の OR」ではなく**申請者の所属課の課長のみ**になった。
  本書の「佐々木綾と山口健太の並列」は成立しない
- **ADR-0048（承認ルートの積み上げ）**: 3 万円以上は**課長 → 部長**の 2 段になった
