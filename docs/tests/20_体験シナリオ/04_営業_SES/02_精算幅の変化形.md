# 体験シナリオ SES-02: 精算幅の変化形（幅内 → 超過 → 控除 → 幅なし → 請求 0 以下 → 切り捨ての境界）

> 作成: 2026-08-09 ／ 所要時間: 約40分 ／ 影響: 2026-09 の工数を 1〜2 行だけ作って何度も書き換える（仕訳を持たないので帳簿には無影響）。ステップ 8・10 で 2026-09 分の SES 請求書・仕訳を生成するが、**後片付けの「発行を取り消す」で完全に消える**。案件の精算上限を一時的に空にする（後片付けで復元）。既存 SES 案件 2 件を一時無効化する（**後片付けで必ず戻す**）。
> 主役: **soumu_bucho**（総務部 部長 山田太郎・経理）のみ。工数も経理の「工数管理（経理）」から代理入力するので、ログインの切り替えは無し。
> 参照分岐: 11_E2E の SES-01（幅内）／SES-02（下限割れ・控除）／SES-03（時間の切り捨て）／SES-04（契約条件未設定）／SES-05（冪等）。
> 同じ案件・同じ月で**実績時間だけを動かし**、精算式が 5 通りに変わるのを一本道で見る。最後に「**生成したあとで工数を足しても金額は直らない**」という運用上いちばん重要な落とし穴を踏む。

## 物語

SES の請求額は「基本料金 ± 精算幅からのはみ出し」で決まる。150h なら 600,000 円、170h なら超過 10 時間分を足して 640,000 円、130h なら控除 10 時間分を引いて 550,000 円——文字で読むと単純だが、**上限 160h を 59 分超えても超過にならない**（時間は切り捨て）、**幅を片方でも空にすると精算そのものが止まる**、**控除が基本料金を食い尽くすと請求されない**といった境界がある。
経理の山田太郎が、月末の精算前に「この案件の式はどう転ぶのか」を一通り試して確かめる回。

## ステップ 1: 準備（隔離と工数 1 行）

**soumu_bucho** でログイン。

まず サイドバー「**業務マスタ**」→「**案件**」で **PRJ-003 金融系SES 山田** と **PRJ-005 保守運用SES 高橋** の「**有効**」を **OFF** にして保存する（2026-09 の実績が 0h のため、放置すると控除計算で黄色行になり一緒に生成されてしまう）。**後片付けで戻す**。

次に サイドバー「**工数管理**」→ 経理は「**工数管理（経理）**」に着地する →「新規作成」で 1 行だけ登録:

| 項目 | 入力値 |
|---|---|
| 担当者 | `開発2部 一般 松本結衣`（**担当者の付け替えは経理だけができる**） |
| 案件 | `ホライゾン商事様・業務システム保守SES 松本` |
| 日付 | `2026-09-15` |
| 時間（分） | `9,000` |
| メモ | `9月 常駐分まとめ（精算幅テスト用）` |

→ 「**保存**」。以降はこの 1 行の「時間（分）」だけを書き換える。

## ステップ 2: 幅内（SES-01）

サイドバー「**営業業務**」→ フレーム内サイドバー「**SES精算・請求**」→ 対象月を **2026-09** にする。

- **期待結果**: 黄色 1 行。実績時間 **150h00m**・請求額 **600,000**・消費税 60,000。
  内容: **`基本 600,000（精算幅 140〜160h） = 600,000（幅内）`**
- **確認ポイント**: 下限 ≦ 時間 ≦ 上限 の間はいくら働いても請求額は動かない。「幅内」という語尾がその印。
- **確認ポイント**: PRJ-003・PRJ-005 は「案件が無効化されているため対象外」。

## ステップ 3: 超過

「工数管理（経理）」で当該行の「時間（分）」を **`10,200`** に書き換えて保存 → 「SES精算・請求」に戻り、対象月を選び直す（別の月にしてから 2026-09 へ）。

- **期待結果**: 実績 **170h00m**・請求額 **640,000**・消費税 64,000。
  内容: **`基本 600,000（精算幅 140〜160h） ＋ 超過 10h×4,000 = 640,000`**
- **確認ポイント**: 超過分だけが**超過単価 4,000 円/h** で加算される（基本料金は据え置き）。控除単価 5,000 とは別の単価が使われていることを式で確かめる。

## ステップ 4: 控除（SES-02）

時間（分）を **`7,800`** に書き換えて保存 → 対象月を選び直す。

- **期待結果**: 実績 **130h00m**・請求額 **550,000**・消費税 55,000。
  内容: **`基本 600,000（精算幅 140〜160h） − 控除 10h×5,000 = 550,000`**
- **確認ポイント**: 下限に 10 時間届かなかったので **控除単価 5,000 円/h** で減額。SES 精算は「働いた分だけ請求」ではなく「**幅からのはみ出しだけを精算**」する契約形態だ、というのが式で読める。

## ステップ 5: 時間の切り捨て境界（SES-03）

時間（分）を **`9,659`** に書き換えて保存 → 対象月を選び直す。

- **期待結果**: 実績時間の表示は **`160h59m`**（分まで表示される）。しかし判定は**時間の整数部**で行われるため **160h = 上限ちょうど**で、
  内容は **`基本 600,000（精算幅 140〜160h） = 600,000（幅内）`**。**59 分は請求に効かない**。

続けて時間（分）を **`9,660`**（＝ちょうど 161h00m）に書き換えて保存 → 対象月を選び直す。

- **期待結果**: **`基本 600,000（精算幅 140〜160h） ＋ 超過 1h×4,000 = 604,000`**。1 分足しただけで 4,000 円動く。
- **確認ポイント（運用の勘所）**: 実績時間は分単位で積み上げるが、**1 時間未満は切り捨て**。「あと 1 分で 1 時間」の月末は請求額が変わるので、工数の締切運用が金額に直結する。下限側も同じで、139h59m は 139h 扱い（控除 1h）になる。

## ステップ 6: 精算幅を外す（SES-04 の隣）

「業務マスタ」→「案件」→ PJ-2026-301 の「**精算上限(h)**」を**空**にして保存（下限を空にしても同じ）。

「SES精算・請求」に戻り対象月を選び直す。

- **期待結果**: 実績は 161h00m のままだが、内容が **`基本 600,000（精算幅なし） = 600,000`** になり、**超過 4,000 円が消える**。
- **確認ポイント**: 精算幅は**下限と上限が両方そろっているときだけ**適用される。片方でも空なら「月額固定」の契約として扱われる。単価だけ入っていても無視される。
- **確認ポイント（似て非なる対象外）**: 「**SES 月額基本料金**」が空／0 の場合は幅の話にすらならず、プランが「**SES 契約条件（月額精算額）が未設定のため対象外**」になる（SES-04）。**幅なし = 満額請求**、**基本料金なし = 請求しない**、という違い。

確認したら「精算上限(h)」を **`160`** に戻して保存する。

## ステップ 7: 請求額が 0 円以下なら対象外

「工数管理（経理）」で時間（分）を **`1`** に書き換えて保存（実質 0 時間。時間は 1 以上が必須なので 0 は入らない）→ 「SES精算・請求」で対象月を選び直す。

- **期待結果**: 実績 **0h01m**・状態 **対象外**。
  内容: **`請求額 0 円以下のため対象外（基本 600,000（精算幅 140〜160h） − 控除 140h×5,000 = -100,000）`**
- **計算**: 600,000 − 140h × 5,000 = **−100,000**。控除が基本料金を食い尽くしてマイナスになった。
- **確認ポイント**: この状態で「**対象月の請求書・仕訳を一括生成**」を押しても「**生成対象はありませんでした**」。**マイナスの請求書は絶対に作られない**（実務では「稼働ゼロの月に契約を止め忘れた」ケースがこれ。プランの理由文で気づける）。
- **確認ポイント**: 除外の理由文に**式がそのまま入る**ので、なぜ 0 円以下なのかが一覧のまま読める。

## ステップ 8: 幅内に戻して生成する

時間（分）を **`9,000`**（150h）に戻して保存 → 対象月を選び直し、黄色 1 行（600,000・幅内）を確認して「**対象月の請求書・仕訳を一括生成**」。

- **期待結果**: トースト「SES 請求 1 件を生成しました」。結果ラベル「2026年9月分: 生成 1件 / 対象外 2件 / 仕訳 No.…」。
- 請求書「SES精算 ホライゾン商事様・業務システム保守SES 松本（2026年9月分）」＝ 発行済・税抜 600,000／消費税 60,000・発行日 9/30・支払期限 10/31・部門「全社共通」・明細摘要 `基本 600,000（精算幅 140〜160h） = 600,000（幅内）（実績 150h00m）`。仕訳（9/30）借方 売掛金 660,000 ／ 貸方 SES売上高 600,000 ＋ 仮受消費税 60,000。入金予定（未確定・660,000）も自動作成。

## ステップ 9: 生成後に工数を足しても再計算されない（最重要）

「工数管理（経理）」で **2 行目**を追加する（日付 `2026-09-28`・案件同じ・時間（分）`1,200` ＝ 20h・メモ `9月 追加稼働の申告漏れ分`）。合計は **170h** になった。

「SES精算・請求」に戻り、対象月を選び直す。

- **期待結果**: 行は **「生成済み」のまま**、内容「**SES 請求書＋売上仕訳を生成済み**」、請求額は **600,000 のまま**。実績時間の表示は 170h00m に更新されるが、**金額は再計算されない**。
- もう一度「一括生成」を押しても「生成対象はありませんでした」（SES-05 の冪等が、そのまま「直せない」に化ける）。
- **なぜ**: 冪等の判定が「案件 × 対象月 × 発行元=ses の請求書が存在するか」なので、**存在する限り金額は請求書の側が正**。工数の後出しは自動では反映されない。
- **運用の教訓**: SES の一括生成は「**工数が締まってから**」。締め切り前に走らせると、あとから出てきた稼働が請求に載らない。

## ステップ 10: 「発行を取り消す」→ 再実行で正しく再計算される

フレーム内サイドバー「**請求書**」→ ステップ 8 の請求書を開き「**発行を取り消す**」（赤）→ ダイアログ「請求書「INV-26-0XX」の発行を取り消します。生成された仕訳 1 本・未確定の入金予定・請求書本体を削除し、未生成の状態に戻します（「定期請求の実行」「SES精算・請求」で再生成できます）。よろしいですか？」→「**発行を取り消す**」。

- **期待結果**: トースト「請求書 INV-26-0XX の発行を取り消しました（必要なら定期請求の実行／SES精算・請求で再生成できます）」。請求書・売上仕訳・未確定の入金予定がまとめて消える。
- **注意**: 入金を消し込んだあとだと「消込済みの入金記録があるため取り消せません（先に入金の取消を行ってください）」で止まる。順序は **入金を取り消す → 発行を取り消す**。

「SES精算・請求」→ 対象月 2026-09 を選び直す。

- **期待結果**: 行が**再び黄色（生成予定）**になり、今度は **170h** で再計算されている:
  **`基本 600,000（精算幅 140〜160h） ＋ 超過 10h×4,000 = 640,000`**（消費税 64,000）。
- 「**対象月の請求書・仕訳を一括生成**」を押す → **640,000 円**の請求書と売上仕訳（借方 売掛金 704,000 ／ 貸方 SES売上高 640,000 ＋ 仮受消費税 64,000）が作られる。明細摘要にも `（実績 170h00m）` が入る。
- **これが SES 精算の直し方の正解**: 金額を手で書き換えるのではなく、**発行取消 → 工数を正して → 再実行**。請求書の摘要に残る式と実績が、常に工数と一致する状態を保てる。

## つまずいたときは

- **式が変わらない**: プランの洗い替えは「画面を開いたとき」と「対象月を変えたとき」だけ。工数・案件を直したら**対象月を選び直す**。
- **実績時間が思ったより多い／少ない**: 同じ案件・同じ月に別の人の工数が入っていないか確認（実績は**案件単位の合計**で、担当者は問わない）。SES 案件は「1 案件 = 1 要員」で運用するのが前提。
- **「時間（分）」に 0 が入らない**: 1 以上が必須。実質ゼロを作るなら `1`（0h01m）を使うか、行そのものを削除する。
- **超過にならない**: 上限を **59 分超えただけ**では超過しない（時間は切り捨て）。1 時間丸ごと超えたかを確認。
- **請求額 0 以下で対象外になる**: 控除単価 × 不足時間が基本料金を超えている。契約条件が実態と合っているかを疑う（改定するなら**未生成の過去月をすべて精算してから**——条件には履歴が無いので、後から過去月を精算すると新条件で計算される。ISSUE-0002 S9）。
- **請求書を作り直したい**: 手で金額を直さない。**入金取消 →「発行を取り消す」→ 工数を正す → 再実行**が唯一の正しい経路。
