# 体験シナリオ 営業-05: 取消の連鎖（入金 → 請求書 → 検収 を逆順に巻き戻す）

> 所要時間: 約35〜45分 ／ 影響: 受注 1・検収 1・請求書 1・入金・仕訳 2 本を作り、**最後にすべて消して元の状態に戻す**。途中で **2026-08 の月次期間を一時的に締める**ので、**必ずステップ 3 の再オープンまで実施すること**
> 主役: **soumu_bucho**（総務部 部長 山田太郎・経理）。パスワードはユーザー名と同じ。
> 「間違えたとき、どこまで戻せるのか」を作った順の逆にたどる一本道。逆操作の正体は**生成した仕訳を消すこと**——だから締め済み期間では止まる。

## 物語

経理の山田太郎は、テックイノベーション向けの受託案件を検収 → 請求 → 一部入金まで通した。
その翌日「先方の検収書の金額が違っていた。いったん全部白紙に戻したい」と連絡が来る。
売上仕訳はもう帳簿に乗っている。どこから、どの順で巻き戻せるのか——実際に押して確かめる。

## 前提

| 項目 | 内容 |
|---|---|
| 取引先 | `株式会社テックイノベーション`（C003・得意先）。案件（プロジェクト）は未設定でよい |
| 会計期間 | 第18期（2026年度）。**2026-04〜06 は締め済み・07 以降オープン**。ステップ 3 で 2026-08 を一時的に締める |
| 採番の目安 | 受注 **SO-26-0XX**／検収 **A-26-0XX**／請求書 **INV-26-0XX**／仕訳 **No.(+1)・No.(+2)**（現在の最終: SO-26-008／A-26-008／INV-26-016／No.83） |
| 巻き戻しの原則 | 逆操作＝**生成した仕訳の削除**。仕訳の期間が締め済みなら削除せず、**赤伝（決算修正仕訳）**へ誘導される |
| 状態遷移の原則 | 遷移はボタンに一本化されている（ADR-0026）。**押せない操作はボタンごと消える**設計なので、「ガードのメッセージ」と「ボタンが出ない」は別物 |

## ステップ 1: 材料を作る（受注 → 検収確定 → 請求書発行）

**soumu_bucho** でログイン → サイドバー「**営業業務**」→ 経理は請求書一覧に着地 → サイドバー「**受注**」→「新規作成」。

| 項目 | 入力値 |
|---|---|
| 取引先 | `株式会社テックイノベーション` |
| プロジェクト | 空のまま |
| 件名 | `検証環境 構築支援` |
| 部門 | `営業部` に変更（経理だけが部門を変えられる） |

明細 1 行: 摘要 `構築支援一式`・数量 `1`・単位 `式`・単価 `500,000` → 「**保存**」。

サイドバー「**検収**」→「新規作成」→ 受注に今作った **SO-26-0XX** を選択。

- **確認ポイント**: 検収額 **500,000**・消費税 **50,000** が自動セットされ、進捗ラベルが「受注額 500,000 円 ／ 検収済み累計（確定） 0 円 ／ 残額 500,000 円」。

検収日=本日 → 「保存」→「**検収を確定（売上計上）**」。

- **期待結果**: トースト「**仕訳 No.(+1) を生成し検収を確定しました（売掛金 550,000 円 / 売上 500,000 円）**」。
  仕訳は 3 行: D 売掛金 550,000 ／ C 受託開発売上高 500,000 ／ C 仮受消費税 50,000。

続けて「**請求書を作成**」→ 請求書詳細へ自動遷移 → 内容を確認して「**発行する**」。

- **確認ポイント**: 明細は検収明細の写しなので、合計 500,000・消費税 50,000 がそのまま入る（金額の手直しは不要）。
- **期待結果**: トースト「請求書 INV-26-0XX を発行しました（入金予定を自動作成。…）」。入金一覧に未確定 **550,000** が 1 行。

## ステップ 2: 一部だけ入金して「一部入金」を作る

サイドバー「**入金**」→ INV-26-0XX の未確定行を開く。

| 項目 | 入力値 |
|---|---|
| 入金日 | **本日**に変更 |
| 入金方法 | `銀行振込`（既定） |
| 入金額（税込） | `300,000`（自動セットの 550,000 から書き換え） |

→ 「**入金を確定（消込）**」。

- **期待結果**: トースト「仕訳 No.(+2): 入金 300,000 円を消し込みました（INV-26-0XX は **一部入金**）」。
  残額 250,000 円の入金予定も自動で作られる（Info トーストも出るが、**成功トーストと重なると読めないことがある**ので、
  入金一覧に未確定 250,000 の行ができていることで確かめる）。
- この時点で、この請求書に紐づく入金は **消込済 1 行（300,000）＋ 未確定 1 行（250,000）の計 2 行**。ステップ 4 でこれが 1 行に統合される。

### 【観察】一部入金の請求書には遷移ボタンが無い

請求書 INV-26-0XX を開いてみる。

- **観察ポイント**: 状態「一部入金」では「**下書きに戻す**」「**取消にする**」がそもそも**表示されない**。遷移ボタンが出るのは **下書き / 発行済 / 取消** のときだけで、一部入金・入金済は**入金側の消込・取消でしか動かない**（ADR-0026: 押せないボタンを見せない）。
- サーバ側には二重ガードとして「**入金記録があるため下書きに戻せません（先に入金の取消を行ってください）**」「**消込済みの入金記録があるため下書きに戻せません（先に入金の取消を行ってください）**」という文言が用意されているが、**UI からは到達しない**。つまり「先に入金を取り消す」以外の道は無い——これが本シナリオの順序（入金 → 請求書 → 検収）の根拠。

## ステップ 3: 締め済み期間のガードを踏む（赤伝への誘導）

**⚠ ここで当月を一時的に締める。必ず本ステップの最後で再オープンすること。**

サイドバー「ホーム」→「**会計業務**」→ 設定 > **会計年度** → 「第18期（2026年度）」を開く。
月次期間のグリッドで **2026-08** の行の 状態 を「**締め済み**」に変更 → 「**登録**」。

- **確認ポイント**: その期間に下書き伝票が残っていると黄色の警告「この期間には下書きの伝票が N 件残っています。締める前に確定または削除を検討してください（保存すると締めは実行されます）」が出る。**ブロックはしない**（締めは保存で実行される）。

### 3-a. 入金の取消がブロックされる

「ホーム」→「営業業務」→ サイドバー「**入金**」→ 消込済の行（300,000）を開き「**入金を取り消す**」（赤）。

- **期待結果**: エラー「**消込仕訳の期間が締め済みのため取り消せません（決算修正仕訳（赤伝）で対応してください）**」。確認ダイアログすら出ない。

### 3-b. 検収の取消は「請求書ガード」が先に出る

サイドバー「**検収**」→ A-26-0XX →「**確定を取り消す**」（赤）。

- **期待結果**: エラー「**請求書 INV-26-0XX が作成済みのため取り消せません（先に請求書側を削除してください）**」。
- **確認ポイント（ガードの順序）**: 締め済みチェックより **請求書の存在チェックが先**。つまり「締めを開けば取り消せる」わけではなく、**請求書を消すのが先**。ガードの順序そのものが正しい作業順を教えている。

### 3-c. 締めを戻す（必須）

会計業務 > 設定 > 会計年度 > 第18期（2026年度）→ **2026-08** の 状態 を「**進行中**」に戻して「**登録**」。

- **補足（一時締めを使わない代替）**: 2026-06 以前の日付で作られた既存の確定済み検収・入金でも同じ文言を確認できる。ただし既存の検収はほとんど請求書が作成済みなので、**3-b の請求書ガードのほうが先に出る**点に注意（既存データを壊さないためにも、押すのはエラーを見るところまでにする）。

## ステップ 4: 入金を取り消す —— 予定が「1 行＝残額」に統合される（RCV）

サイドバー「**入金**」→ 消込済の行（300,000）→「**入金を取り消す**」（赤）。

- ダイアログ: 「**消込仕訳 No.(+2) を削除して入金を未確定に戻します。よろしいですか？**」→「**取り消す**」。
- **期待結果**: トースト「**仕訳 No.(+2) を削除し、入金予定を残額 550,000 円に統合しました（入金日・金額を実額に修正して確定してください）**」。

**何が起きたか**（4 つ同時に起きる）:

| 対象 | 変化 |
|---|---|
| 仕訳帳 | No.(+2)（消込仕訳）が**消える**。売上仕訳 No.(+1) は**残る** |
| 入金一覧 | この請求書の行が **2 行 → 1 行**。残った 1 行は未確定・金額 **550,000**・備考が「**入金の取消により残額の入金予定に戻りました（入金日・金額・入金方法を実額に修正して確定してください）**」に書き換わる |
| 請求書 | 一部入金 → **発行済** に戻る（消込済み入金の合計 0 から再計算） |
| 売掛残高 | 残額が 550,000 に戻る |

- **確認ポイント（設計の妙）**: 確定と取消をどの順に何回繰り返しても「**未確定はちょうど 1 行＝残額**」に収束する（ADR-0033 追補）。取り消した本人の行を残額の予定に書き換え、他の未確定行は削除する実装。

## ステップ 5: 請求書を「下書きに戻す」→ 再発行する

請求書 INV-26-0XX を開く。発行済に戻ったので「**下書きに戻す**」（赤）が**現れている**。

→ 「**下書きに戻す**」。

- **期待結果**: トースト「請求書を下書きに戻しました」。状態「下書き」。
  - **未確定の入金予定（550,000）が消える**（入金一覧から該当行が無くなる）。
  - 閲覧専用ロックが外れ、明細も金額も編集でき、「**保存**」ボタンが復活する。「この請求書を削除」（赤）も現れる。
- **確認ポイント**: 手動・検収由来の請求書は「下書きに戻す」。**定期請求・SES で自動生成された請求書はこのボタンが「発行を取り消す」に置き換わり**、生成された売上仕訳ごと削除される（ADR-0033。そちらは `03_営業_定期請求/` の領分）。

もう一度「**発行する**」。

- **期待結果**: 入金予定（550,000）が**作り直される**。入金一覧に未確定 1 行が復活。

## ステップ 6: 「取消にする」—— 売上仕訳は残る

請求書 INV-26-0XX で「**取消にする**」（赤）。

- ダイアログ: 「**請求書「INV-26-0XX」を取消にしますか？（入金消込・売掛残高の対象から外れます。計上済みの売上仕訳はそのまま残るため、貸倒れ等は別途振替伝票で処理してください）**」→「**取消にする**」。
- **期待結果**: トースト「請求書 INV-26-0XX を取消にしました」。状態「取消」。未確定の入金予定が**削除される**。

**ここで帳簿を見に行く**（本ステップの核心）:

- 会計業務 > 帳簿 > 仕訳帳: **売上仕訳 No.(+1) はそのまま残っている**。
- **意味**: 請求書の「取消」は**請求という書面の無効化**であって、**売上の取消ではない**。二重発行の整理や貸倒れの前処理に使う操作で、収益の取り消し・貸倒損失の計上は**別途 振替伝票**で行う（この設計の解説は 11_E2E の COR-01〜03）。
- サイドバー「**売掛残高**」: 取消の請求書は集計対象から外れ、状態フィルタを空にしても**一覧に出てこない**（COR-03）。
- サイドバー「**入金**」→ 未確定行を開いて請求書ドロップダウンを覗くと、候補は **発行済・一部入金だけ**。取消の請求書は**選べない**。

## ステップ 7: 「取消を戻す」—— 入金予定が作り直される

同じ請求書で「**取消を戻す**」（赤）。

- **期待結果**: トースト「請求書 INV-26-0XX を発行済に戻しました」。状態「発行済」。
- **確認ポイント**: サイドバー「入金」に**未確定 550,000 が再び現れる**。取消で消した入金予定を、復帰と同時に作り直している（消込対象に戻すため）。
- **注意**: 復元されるのは「予定」だけ。取消前に**消込済みの入金があった場合はそもそも「取消にする」が拒否される**（「消込済みの入金記録があるため取消にできません（先に入金の取消を行ってください）」）。

## ステップ 8: 検収の「確定を取り消す」—— 請求書を消してから

サイドバー「**検収**」→ A-26-0XX →「**確定を取り消す**」（赤）。

- **期待結果（1 回目・拒否）**: エラー「**請求書 INV-26-0XX が作成済みのため取り消せません（先に請求書側を削除してください）**」。

請求書に戻り、順に片付ける:

1. 「**下書きに戻す**」（未確定の入金予定が消える）
2. 「**この請求書を削除**」（赤）→ ダイアログ「請求書「INV-26-0XX」を削除しますか？（元に戻せません）」→「**削除する**」
   - **確認ポイント**: 削除できるのは**下書きのときだけ**。入金記録が 1 件でも残っていると「**入金記録があるため削除できません**」で止まる（**未確定の予定も含む**）。手順 1 の「下書きに戻す」が予定を先に片付けているので通る。

再び 検収 A-26-0XX →「**確定を取り消す**」。

- ダイアログ: 「**売上仕訳 No.(+1) を削除して検収を下書きに戻します。よろしいですか？**」→「**取り消す**」。
- **期待結果**: トースト「**検収の確定を取り消し、下書きに戻しました**」。
  - 仕訳帳から **No.(+1) が消える**（売掛金・売上・仮受消費税の 3 行ごと）。
  - 検収は「下書き」に戻り、編集できるようになる。「この検収を削除」（赤）が現れる。
  - 進捗ラベルの「検収済み累計（確定）」が **0** に戻り、残額が受注額と同じ 500,000 に戻る。

## ステップ 9: どこまで戻せるか（まとめ）

| 前進の操作 | 逆操作 | 消える仕訳 | 阻む条件 |
|---|---|---|---|
| 検収を確定（売上計上） | **確定を取り消す** | 売上仕訳 | 請求書が存在する／仕訳の期間が締め済み |
| 請求書を発行 | **下書きに戻す** | なし（未確定の入金予定を削除） | 一部入金・入金済（ボタンが出ない）／定期・SES 生成分は「発行を取り消す」に置換 |
| 請求書を発行 | **取消にする** ⇄ **取消を戻す** | なし（売上仕訳は残る） | 消込済みの入金があると取消不可 |
| 入金を確定（消込） | **入金を取り消す** | 消込仕訳 | 消込仕訳の期間が締め済み |
| 伝票を確定（posted） | — | — | **確定伝票は削除できない**。訂正は赤黒（反対仕訳＋再起票） |

**原則**: 自動生成された仕訳は「生成した画面の逆操作」でだけ消せる。仕訳画面から直接消す道は無い。
そして**締め済み期間に入った仕訳はどの逆操作からも消せない**——そこから先は赤伝の世界。

## 後片付け（元の状態に戻して終わる）

ステップ 8 の続きとして、以下を実施する。

1. **検収**: A-26-0XX を開き「**この検収を削除**」（赤）→ ダイアログ「検収「A-26-0XX」を削除しますか？（元に戻せません）」→「削除する」。
2. **受注**: SO-26-0XX を開き「**この受注を削除**」（赤）→「削除する」（検収が消えていれば削除できる）。
3. **会計期間の確認（重要）**: 会計業務 > 設定 > 会計年度 > 第18期（2026年度）で **2026-08 が「進行中」**であることを再確認する（ステップ 3-c の戻し漏れ防止）。
4. **仕訳帳の確認**: No.(+1)・No.(+2) が存在しないこと。年度内の最終は **No.83** に戻っており、次に起票する伝票はまた No.(+1) から始まる。

これで DB は本シナリオ実行前と同じ状態になる（請求書番号 `INV-26-0XX` も再び採番可能になる）。

## つまずいたときは

- **「入金を取り消す」が見当たらない**: 未確定行を開いている（このボタンは**消込仕訳がある行**にだけ出る）か、経理でないユーザーで見ている。入金一覧の消込状態「消込済」で探す。
- **「下書きに戻す」が見当たらない**: 状態が **一部入金・入金済**（先に入金を取り消す）／**取消**（先に「取消を戻す」）／**定期請求・SES の自動生成分**（「発行を取り消す」に置き換わっている）のいずれか。
- **締め済みエラーが消えない**: 見るべきは**入金日や検収日ではなく仕訳日**。仕訳日が属する月を 会計業務 > 設定 > 会計年度 で「進行中」に戻す。
- **検収の確定取消が「請求書が作成済み」で止まる**: 順序どおり、請求書を「下書きに戻す」→「この請求書を削除」してから再挑戦する。請求書を残したまま検収だけ戻す道は無い（売上と請求の整合を守るため）。
- **請求書が削除できない（「入金記録があるため削除できません」）**: 未確定の入金予定が残っている。いったん「下書きに戻す」を押し直すと予定が片付く。それでも残る場合は 入金一覧で該当請求書の行を確認する。
- **仕訳番号が本書と違う**: 番号は年度内の最終 +1。削除すればその番号は空くので、次の起票で同じ番号が振られる。金額と貸借が合っていれば正常。
