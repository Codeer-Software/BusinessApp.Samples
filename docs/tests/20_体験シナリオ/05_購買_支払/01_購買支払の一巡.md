# 体験シナリオ 購買-01: 購買支払の一巡（受領 → 未払計上 → 支払予定表 → 支払）

> 所要時間: 約15分 ／ 影響: 仕入先請求書 1 件・仕訳 2 本追加（既存データは変更しない）
> 主役: **soumu_bucho**（総務部 部長 山田太郎・経理）。パスワードはユーザー名と同じ。
> 買掛管理の王道一本道。「請求書が届く → 費用を計上する（発生主義）→ 支払期日を管理する → 払う」を最初から最後まで通し、支払予定表とポータルのアラート連動も見る。

## 物語

グランメゾン印刷から、封筒・社用箋の印刷物一式 22,000 円（税込）の請求書が届いた。
支払期限は 8 月中旬。受領登録 → 未払計上 → 支払予定表で期日管理 → 銀行振込で支払、という月次の買掛サイクルを一巡する。

## 前提

| 項目 | 内容 |
|---|---|
| ログインユーザー | soumu_bucho（経理機能フラグ保有。購買・支払は経理専用） |
| 会計期間 | 第18期（2026年度）。当月（2026-08）の月次期間がオープンであること |
| 既存データ | 仕入先請求書に 受領 2 件・未払計上済 2 件・支払済 1 件が入っている（このシナリオでは触らない）。SL-26-0705（支払期限 2026-07-10）が**期限超過**の実例として支払予定表に見えているはず |
| 仕訳番号の目安 | **具体値は書かない**（年度内の最終 +1 で採番されるので、他の台本を先に流せば必ずズレる）。本書では **No.(+1) / No.(+2)** と書く。金額と貸借が合っていれば正常 |

## ステップ 1: 請求書の受領登録

ログイン → 業務ポータル → サイドバー「**購買・支払**」。

- **確認ポイント（着地）**: フレームの着地は**仕入先請求書の一覧そのもの**（トップページは無い）。サイドバーは「ホーム／仕入先請求書／支払予定表／振込データ作成」の 4 つ。

「新規作成」で入力:

| 項目 | 入力値 |
|---|---|
| 請求書番号 | `GM-2608-042` |
| 仕入先 | `グランメゾン印刷株式会社` |
| 受領日 | 本日（自動セット済み） |
| 請求日 | 本日 |
| 支払期限 | **本日から 5 日後**（例: 2026-08-14。後で「まもなく期限」警告を見るため） |
| 費用科目 | `消耗品費` |
| **部門** | **`総務部`**（**必須。未選択だとステップ 2 で止まる**——下の確認ポイント参照） |
| 税区分 | `課税仕入 10%` |
| **案件（任意）** | **空欄のまま**（社内で使う印刷物なので案件に紐づかない） |
| 金額（税込） | `22,000` |
| 摘要 | `封筒・社用箋 印刷物一式` |

→ 「登録」。

- **確認ポイント**: 状態は「**受領**」で固定表示（手で変えられない。ボタン経由でのみ遷移する設計）。この時点では**帳簿は無変化**（受領登録は帳簿外のメモ）。ただし支払予定表には既に載る。
- **確認ポイント（部門は「保存」では任意・「未払計上」では必須）**: 部門を空のまま登録することは**できる**が、
  ステップ 2 の未払計上で赤トースト「**部門を選択してください（損益科目の仕訳には部門が必要です）**」で止まる（ADR-0056）。
  費用科目が損益科目（費用・収益）のときだけ効くガードで、**経理が画面を見て押す操作なので全社共通で黙って埋めずに選ばせる**設計。
- **確認ポイント（案件・ADR-0064）**: 「案件（任意）」を選ぶと、**未払計上・支払の両方の仕訳の全明細に引き継がれ、
  案件別損益（経営管理 > 案件損益）の「直課費用」に乗る**。外注費・SES 仕入のように案件に紐づく仕入では**必ず選ぶ**。
  今回は社内経費なので空欄が正解——空欄でも登録も未払計上も通る（案件は最後まで任意）。
  案件を付けた場合の一巡は `05_購買_支払/03_仕入先請求書の変化形.md` ステップ 3 で見る。

## ステップ 2: 未払計上（発生主義の費用計上）

保存した請求書の詳細で「**未払計上（仕訳生成）**」を押す。

- **期待結果**: トースト「未払計上 No.(+1) を生成しました（借方 20,000 円+税 / 貸方 買掛金 22,000 円）」。状態が「**未払計上済**」に進む。
- **帳簿の確認**: ホーム → 会計業務 → 帳簿 > 仕訳帳。請求日の日付で 3 行 —— 借方 **消耗品費 20,000** ＋ **仮払消費税 2,000** ／ 貸方 **買掛金 22,000**（税込 22,000 の内税分解）。起票日は**請求日**（支払日ではない＝発生主義）。（PUR-03）

## ステップ 3: 支払予定表で期日管理

サイドバー「**支払予定表**」。

- **確認ポイント**:
  - GM-2608-042 の行に「期限まで(日)」= 5 前後、警告列に「**まもなく期限**」（閾値 PAY_DUE_SOON_DAYS=7 日以内）。
  - 既存の SL-26-0705 の行には「**⚠ 期限超過**」・期限まで(日)がマイナス。
  - 最終行に**合計行**（仕入先欄が「合計」）。
  - **この画面は完全に表示専用**: 行をクリックしても詳細に飛ばず、支払を実行するボタンも無い。支払は「仕入先請求書」画面に戻って行う導線になっている（体験メモ: ここが一手間と感じるかどうかは UX 観点で要チェック）。

サイドバー「ホーム」でポータルへ戻る。

- **確認ポイント**: アラートに「**⚠ 支払期限: 超過 N 件 ／ 7日以内 M 件**」が出ており、M に今回の 1 件が含まれている。クリックすると支払予定表へ直行する。

## ステップ 4: 支払登録（買掛金の消込）

「仕入先請求書」→ GM-2608-042 を開き「**支払登録（消込仕訳）**」。

- **期待結果**: トースト「支払仕訳 No.(+2)（22,000 円）を生成し支払済にしました」。状態「**支払済**」・支払日=本日（自動）。
- **仕訳**: 借方 **買掛金 22,000** ／ 貸方 **普通預金 22,000**（本日付・税処理なし）。
  - **確認ポイント**: 支払口座を選ばずに実行したので、貸方は**普通預金(1020)へのフォールバック**。支払口座に「MB01 メインバンク 普通預金」を選んでも結果は同じ科目になる（口座マスタの帳簿科目が 1020 のため）。
- 支払予定表に戻ると GM-2608-042 の行が**消えている**（未払いのものだけが載る）。ポータルの「7日以内」件数も 1 減っている。

## ステップ 5: 総仕上げ

| 画面 | 見えるもの |
|---|---|
| 会計業務 > 帳簿 > 仕訳帳 | No.(+1)（費用計上 3 行）と No.(+2)（支払 2 行） |
| 会計業務 > 帳簿 > 出納帳（普通預金） | 本日 出金 22,000 の行 |
| 会計業務 > 財務帳票 > 合計残高試算表 | 買掛金が計上と消込で往復し、正味 0（このシナリオ分） |

これで「届いた請求書が費用になり、期日管理され、銀行から払われて買掛が消える」一巡が完了。

## つまずいたときは

- **「未払計上」ボタンが出ない**: 状態が「受領」でない、または保存前。受領状態の保存済み請求書でのみ出る。
- **「部門を選択してください（損益科目の仕訳には部門が必要です）」で止まる**: 部門が空のまま未払計上を押した（ADR-0056）。詳細画面で部門を選んで「登録」してから押し直す。**既存のデモデータ 5 件は部門が空のまま**（このガードが入る前に作られたもの）なので、それらを未払計上しようとすると同じ所で止まる。
- **「請求日の期間は締め済みです」**: 請求日が締め済み月（2026-06 以前）に入っている。請求日をオープン期間にするか、会計年度画面で再オープンする。
- **仕訳番号が本書と違う**: 年度内の最終+1 で採番されるため、他の操作を挟めばずれる。金額と貸借が合っていれば正常。
- **ポータルのアラート件数が合わない**: 既存の受領・未払計上済の請求書も数えられている。件数の増減（+1/−1）で確認する。
