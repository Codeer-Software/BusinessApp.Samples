# 体験シナリオ 経営-01: 予算と予実の一巡（予算入力 → 予実対比 → 警告 → ポータル連動）

> 作成: 2026-08-09 ／ 所要時間: 約25分 ／ 影響: 予算明細 12 行追加（後片付けで削除可）・制度閾値を一時変更（必ず戻す）。仕訳は増えない
> 主役: **soumu_bucho**（総務部 部長 山田太郎・経理）→ 途中で **kaihatsu1_bucho**（開発1部 部長 田中宏・承認者）視点。パスワードはユーザー名と同じ。
> 予算を立て、消化状況を監視し、警告がポータルまで届く——管理会計の見張り塔を一巡する。

## 物語

期中だが、営業部の会議費に年間予算を付けることになった。経理の山田太郎が予算を登録し、予実対比で全社の消化状況を確認する。あわせて「予算警告はどこまで届くのか」（経理・部長・一般でどう見え方が変わるか）を検証する。

## 前提

| 項目 | 内容 |
|---|---|
| 対象年度 | 第18期（2026年度）。年度参照はすべて「第18期（2026年度）」形式のラベル表示 |
| 既存予算 | 第18期に 2 部門分・36 行が登録済み（目安）。本シナリオは**まだ予算が無い 部門×科目 の組み合わせ**を使う |
| 警告閾値 | `BUDGET_ALERT_RATE` = 80(%)（業務マスタ > 税制 > 制度閾値）。**消化率が 80% ちょうどでも点灯**（以上判定） |
| 重要仕様 | 予実対比の既定検索（現在年度＋非経理は自部門）は **`?initialize_search=true` 付きの遷移でのみ発火**する。サイドバー・ポータル経由なら自動で付く。URL 直打ちだと検索条件は空＝0件表示 |

## ステップ 1: 予算の 12ヶ月均等登録（山田太郎）

**soumu_bucho** でログイン → サイドバー「**経営管理**」（経理なので ManagementFull に着地・予実対比が開く）→ サイドバー 予算 > 「**予算入力**」。

入力値:

| 項目 | 入力値 |
|---|---|
| 会計年度 | `第18期（2026年度）` |
| 部門 | `営業部` |
| 勘定科目 | `会議費` |
| 年間予算額 | `1,000,000` |

- **確認ポイント**: 部門の候補には**部しか出ない**（課は選べない=予算は部単位）。勘定科目の候補は**費用科目のみ**（売上高などは出ない）。

→ 「**12ヶ月均等で登録**」。

- **期待結果**: 結果ラベルに「…12ヶ月分を登録しました（**月額 83,333 円 / 期末月 83,337 円**、新規 12・上書き 0）」。1,000,000÷12 の端数 4 円は**期末月（第12月）に寄せられる**。
- 予算 > 「予算明細」で 営業部×会議費 の 12 行を確認できる。

同じ条件で年間予算額だけ `1,200,000` に変えて再実行してみる。

- **期待結果**: 「（月額 100,000 円 / 期末月 100,000 円、新規 0・**上書き 12**）」——再実行は洗い替えでなく**同じ月への上書き**。

## ステップ 2: 予実対比と既定検索の仕様

サイドバー 予算 > 「**予実対比**」をクリック。

- **期待結果**: 開いた時点で**検索済み**——年度に「第18期（2026年度）」がセットされている（サイドバー経由なので既定検索が発火）。経理なので**部門は空＝全社横断**。
- **確認ポイント**:
  - ステップ 1 で登録した 営業部×会議費 の行が出る（実績が無ければ 消化率・警告は空欄）。
  - 予算ゼロで実績だけある科目も行として出る（消化率は空）。
  - 部門の付いていない実績は「**(部門未設定)**」行に集まる。
- **仕様の確認（重要）**: ブラウザのアドレスバーで同じ URL を `?initialize_search=true` **無し**で直打ちして開き直すと、検索条件が空で **0 件**になる。「サイドバー/ポータルから開けば検索済み、直リンクは自分で検索」という挙動の差を体感しておく。

## ステップ 3: 警告を意図的に点灯させる（80% 境界）

予実対比で「**実績があるのに予算が未登録**（消化率が空）」の行をひとつ選び、その**実績額 A** をメモする。

1. 予算入力で その部門×科目 に 年間予算 = **A × 100 ÷ 80（円未満切り捨て）** を登録 → 予実対比を再検索。
   - **期待結果**: 消化率 **80%**・警告列に「**⚠ 予算警告**」（80 ちょうどで点灯する以上判定）。
2. 年間予算を **A × 1.3 前後**に上げて再登録 → 再検索。
   - **期待結果**: 消化率が 76〜77% に下がり、警告が**消える**。

## ステップ 4: 警告はどこまで届くか（ポータルの部門スコープ）

1. ステップ 3-1 の状態（どこかの部門に警告あり）に戻し、サイドバー「ホーム」でポータルへ。
   - **期待結果（経理）**: アラート欄に「**⚠ 予算警告: N 部門**」。クリックすると予実対比に**検索済み**で着地する。
2. ログアウト → **kaihatsu1_bucho** でログイン。
   - **期待結果（非経理の承認者）**: 警告部門に**開発1部が含まれる場合のみ**「⚠ 予算警告: **あなたの部門（開発1部）**」が出る。他部門だけの警告なら**何も出ない**（自部門スコープ）。
   - サイドバー「経営管理」→ **ManagementApprover** に着地（承認者用の変種）。メニューは「予実対比」「予算明細」のみ。予実対比は**自部門（開発1部）で検索済み**になっている。
   - 予算明細は**閲覧できるが**、行を編集して保存しようとすると拒否される（書込は経理のみ）。
3. 一般社員（例: kaihatsu2_shinjin）でログインすると、ポータルにアラート区画自体が**出ない**。

## ステップ 5: 閾値マスタの即効性（後片付け込み）

**soumu_bucho** に戻り、サイドバー「ホーム」→「**業務マスタ**」→ 税制 > 「**制度閾値**」→ `BUDGET_ALERT_RATE` を `80` → `50` に変更して登録。

- **期待結果**: 予実対比を再検索すると、消化率 50% 以上の行に警告が増える。ポータルの「⚠ 予算警告: N 部門」の N も増える（アプリ再起動不要・SQL が毎回マスタを読む）。

**後片付け（必須）**:
1. `BUDGET_ALERT_RATE` を **80 に戻す**。
2. ステップ 1・3 で登録した予算が不要なら、予算 > 予算明細 で該当 12 行×組み合わせ分を削除する（残しても実害はないが、予実対比に行が出続ける）。

## つまずいたときは

- **予実対比が 0 件**: 検索条件が空のまま（直リンクで開いた）。年度を選んで検索するか、サイドバーから開き直す。
- **「予算の登録は経理のみ実行できます」**: 経理機能フラグの無いユーザーで予算入力を実行した。soumu_bucho で操作する。
- **80% ちょうどで点灯しない**: 消化率は整数切り捨て。実績 A に対し予算を A×100÷80 より大きくすると 79% に落ちる。計算をやり直す。
- **ポータルに警告が出ない**: 対象部門に警告が無い（非経理は自部門のみ表示）。経理でログインして全社の警告有無を先に確認する。
