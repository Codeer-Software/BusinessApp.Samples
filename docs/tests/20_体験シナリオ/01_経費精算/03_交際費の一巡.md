# 体験シナリオ 経費-03: 交際費の一巡（必須3項目 → 課長＋総務 → 精算）

> 作成: 2026-08-09 ／ **更新: 2026-08-09 ADR-0048（承認ルートの積み上げ化）を反映——30,000 円以上の交際費が「課長 → 部長 → 総務」の3段になった（ステップ3）** ／ 所要時間: 約25分 ／ 影響: 仕訳 2 本追加（22,000 円の交際費）。33,000 円の申請は途中でキャンセルして消す
> 主役: **kaihatsu1_ippan**（開発1部 第一課 小林美咲）→ **kaihatsu1_kacho1**（第一課長 山本由美）→ **soumu_kacho1**（総務 第一課長 石川真理）→ **soumu_bucho**（経理 山田太郎）
> 交際費だけの特別ルール——3つの必須項目と、金額がいくら少なくても総務が必ず同席する承認ルート——を体験する。

## 物語

小林美咲がテックイノベーションの担当者2名と会食した（22,000 円）。交際費は税務上の要注意費目なので、このアプリでは「誰と・何人で・何のために」の記録が必須で、承認にも必ず総務が入る。
ついでに 30,000 円以上だと部長ルートに格上げされることも確かめる。

## 前提

| 項目 | 内容 |
|---|---|
| 交際費のルート | 〜29,999 円=**課長まで＋総務**（課長 → 総務の2段）／30,000 円〜=**部長まで＋総務**（課長 → 部長 → 総務の3段）。一般費目と違い、少額でも必ず総務が付く |
| 少額だけ部長を飛ばす理由 | 5,000 円の会食に部長決裁を求めるのは重い、という意図的な例外（ADR-0048）。部長を通したい会社は承認ルート判定の交際費2行をどちらも `経費_部長まで＋総務` に向ければよい |
| 仕訳番号 | 現在の最終+1・+2（目安。読み替え可） |

## ステップ 1: 必須3項目のブロックを味わう（EXP-R05 前段）

**kaihatsu1_ippan** でログイン → サイドバー「**経費精算**」→ 新規作成。

| 項目 | 入力値 |
|---|---|
| 件名 | `テックイノベーション様 会食` |
| 金額（税込） | `22,000` |
| 利用日 | 本日 ／ 費目 | `交際費` |

- **確認ポイント**: 費目を交際費にした瞬間、「**接待の相手先／参加人数／接待の目的**」の3欄が出現する（他の費目では出ない）。

3欄を**空のまま**「申請」→ **期待結果**: 「交際費は相手先・参加人数・目的の入力が必須です」でブロック。

## ステップ 2: 正しく入力して申請（EXP-R05）

| 項目 | 入力値 |
|---|---|
| 接待の相手先 | `株式会社テックイノベーション 佐藤様・鈴木様` |
| 参加人数 | `4` ／ 接待の目的 | `販売管理システム構築の御礼と次期案件の相談` |

→ 「申請」。

- **期待結果**: 承認フロー `▶山本由美 → 石川真理` の **2段**。22,000 円という少額でも総務（石川真理）が付く——金額でなく**費目**が効いている。
- 石川さんにはまだ通知が来ていない（1段目の承認後に届く）。

## ステップ 3: 30,000 円の交際費は部長段が挟まる（EXP-R06）

もう1本、`部内歓迎会` ／金額 `33,000`／交際費／3項目入力 で申請。

- **期待結果**: `▶山本由美 → (田中宏,渡辺剛) → 石川真理` の **3段**。**30,000 円以上は課長と総務の間に部長段が積み上がる**（課長が抜けるのではない＝ADR-0048）。ステップ2（22,000 円）との差は部長段だけ。
- 確認できたらこの申請は「**キャンセル**」→「**この下書きを削除**」で片付ける（本シナリオで精算まで進めるのは 22,000 円の1本だけ）。

## ステップ 4: 課長 → 総務の順次承認

1. **kaihatsu1_kacho1**（山本由美）でログイン → 承認待ちに着地 → 開く → 「**承認**」。
   - **期待結果**: フローが `✓山本由美 → ▶石川真理` に進む。**この瞬間に石川さんへ「承認依頼」通知**が飛ぶ。
2. **soumu_kacho1**（石川真理）でログイン → ポータルに「あなたの承認待ち: 1件」→ 開いて「**承認**」。
   - **期待結果**: 最終承認。申請者に「承認されました」通知。精算ステータス「承認済」。

## ステップ 5: 経理精算（仕訳の中身に注目）

**soumu_bucho** でログイン → 経費精算（精算処理待ちに着地）→ 該当行を開く → 「**仕訳を生成**」。

- **期待結果**: 3行仕訳 — 借方 **交際費 20,000** ＋ **仮払消費税 2,000** ／ 貸方 **未払金 22,000**（内税分解）。部門は「開発1部」。
- 続けて「**精算済にする**」→「**完了にする**」（経費-01 と同じ流れ）。

## つまずいたときは

- **3項目の欄が見えない**: 費目が「交際費」になっているか確認（費目マスタの「交際費フラグ」で出し分けている）。
- **総務の承認者が石川真理でない**: 承認フローテンプレート「経費_課長まで＋総務」（旧名「経費_課長＋総務」）の個人指名が変更されていないか、システム管理 > 承認 > 承認フローテンプレート で確認。
- **山本由美の承認前に石川真理の受信箱に出る**: 出ないのが正しい（順次到達）。出ていたら不具合として記録を。
