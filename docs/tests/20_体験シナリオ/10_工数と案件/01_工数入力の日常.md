# 体験シナリオ 工数-01: 工数入力の日常（自分の入力 → 他人の行 → 経理の代理修正 → 締めとの関係）

> 所要時間: 約20分 ／ 影響: 工数（time_entries）を数行追加（仕訳・帳簿への影響はゼロ。後片付けで削除可能）
> 主役: **kaihatsu2_shinjin**（開発2部 一般 高橋健）→ **soumu_bucho**（総務部 部長 山田太郎・経理）。パスワードはユーザー名と同じ。
> 工数入力の「本人しか触れない」境界と、経理の代理修正窓口、そして**工数は月次の締めにブロックされない**という会計との温度差を体験する。

## 物語

開発2部の新人・高橋健が、今週担当した社内業務改善タスクの工数を入力する。
入力し忘れていた先月（締め済みの6月）の分も遅れて入力し、間違えた行は経理の山田太郎が代理で直す——工数管理の日常業務を一巡する。

## 前提

| 項目 | 内容 |
|---|---|
| 権限 | 工数入力は全社員（工数入力フラグ・既定ON）。工数管理（経理）は経理機能フラグ保有者のみ |
| 行の保護 | 他人の行はサーバ側の書込条件（担当者=自分）で保護されている。経理だけが TimeEntryAdmin（工数管理（経理））で全員分を編集できる |
| 会計期間 | 第18期。**4〜6月は締め済み・7月以降オープン**であること（締め済み月への入力がブロック「されない」ことを見るシナリオなので、この状態が重要） |
| 使う案件 | `PRJ-006 社内業務改善`（社内・有効）。他の有効案件でも可 |

## ステップ 1: 自分の工数を入力する（高橋健）

**kaihatsu2_shinjin** でログイン → サイドバー「**工数管理**」→ 工数入力に着地。

- **確認ポイント（検索初期化）**: サイドバー経由で開くと検索条件「担当者」に**自分（高橋健）が既定セット**されている。一覧に出るのは自分の行だけ（0件でも正常）。

「新規作成」で入力フォームを開く。

- **確認ポイント（既定値）**: 担当者=**自分**（かつ**読み取り専用**——般社員は他人名義で登録できない）、日付=**今日**、時間=**480**（分。60分=1時間、480=8時間のヒント表示あり）。

| 項目 | 入力値 |
|---|---|
| 案件 | `社内業務改善` |
| 日付 | 今日（既定のまま） |
| 時間（分） | `480` |
| メモ | `業務フロー整理` |

→ 「登録」。同様にもう 1 件、昨日の日付で `240` 分を登録する。

- **期待結果**: 一覧（日付降順）に自分の 2 行が並ぶ。行には削除ボタンが出る（自分の行だから）。

## ステップ 2: 他人の行との境界を見る

検索条件の「担当者」を**クリアして検索**する。

- **期待結果**: **全員分の工数が見える**（読み取りは制限されていない。7月分の他メンバーの行が並ぶ）。
- **確認ポイント**: 他人の行には**削除ボタンが出ない**。開いても読み取り専用で保存できない（サーバ側の書込条件による多層防御）。
- **気づきメモ（UX観察）**: URL 直打ちやブラウザバックで開いた場合は「担当者=自分」の初期絞り込みが効かない（初期化はサイドバーリンクの `?initialize_search=true` 経由でのみ発火）。この挙動をどう感じるかはメモしておく価値あり。

## ステップ 3: 締め済み月に入力できてしまう（仕様）

新規作成で日付を **`2026-06-15`（締め済みの6月）** にし、案件=社内業務改善・時間=`120` で「登録」。

- **期待結果**: **エラーにならず登録できる**。振替伝票なら「取引日の期間は締め済みです」と弾かれる日付でも、工数は通る。
- **会計的な意味**: 工数は管理会計レイヤ（配賦・案件損益）の入力であり仕訳を作らないため、月次締めの対象外（ADR-0009）。ただし後から工数を足すと**人件費配賦・案件損益の6月の数字が動く**。締め済み月の実績を確定値として扱いたい場合は運用ルールで縛る必要がある——という設計の割り切りを体験するステップ。
- 対比: SES 精算・請求（営業業務）だけは工数を読む処理側で「対象月の期間は締め済みです」と止まる。

## ステップ 4: 経理の代理修正窓口（山田太郎）

ログアウト → **soumu_bucho** でログイン → サイドバー「**工数管理**」→ 経理は **工数管理（経理）** に着地する（同じテーブルの経理用窓口）。

- **確認ポイント**: こちらは検索の既定絞り込みが**無い**（最初から全員分）。高橋健の 6/15 の行を開くと**編集できる**（時間を 120→180 に修正 → 登録）。担当者の**付け替え**も経理だけができる（試したら元に戻すこと）。
- **任意（管理会計への波及）**: サイドバー「ホーム」→「経営管理」→ 案件損益/人件費配賦 で 対象=第18期・月No=`3`（=6月。月Noは期首からの番号）を検索。高橋健には月次人件費コストが未登録なので、工数行は出るが配賦額は 0（コスト登録があって初めて金額が付く）——「工数だけでは原価にならない」ことが見える。

## ステップ 5: 後片付け

**kaihatsu2_shinjin** に戻り（または soumu_bucho のまま工数管理（経理）で）、本シナリオで登録した行（今日・昨日・6/15 の 3 行）を削除する。

- **期待結果**: 一覧から消える。仕訳・帳簿には最初から影響していないので、これで完全に原状回復。

## つまずいたときは

- **一覧に何も出ない**: 検索条件「担当者」が自分になっている（自分の行が 0 件なら空で正常）。クリアして検索すれば全員分が出る。
- **案件がプルダウンに出ない**: 案件マスタの「有効」が OFF。なお状態を「完了」にしても候補からは消えない（消えるのは有効 OFF のみ。→ 工数-02）。
- **他人の行が保存できない**: 仕様（担当者=自分の行のみ書込可）。直すのは本人か、経理が工数管理（経理）から。
- **「工数管理（経理）」が見えない**: 経理機能フラグ保有者のみ。soumu_bucho で操作する。
