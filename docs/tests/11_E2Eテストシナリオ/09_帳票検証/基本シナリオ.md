# 09_帳票検証 基本シナリオ（BS・PL・TB ほか全帳票の整合性検証）

> 改訂: 2026-07-10（ページフレーム分割・組織再編・sysadmin ロールに追随。金額・仕訳番号は不変）
> 更新: 2026-08-02（部品アーキテクチャ再編 ADR-0040/0041 反映——財務帳票は会計（Accounting）ワークスペースの【財務帳票】グループ。**資金繰り予測（9-9）だけは経営管理（ManagementFull）へ移動**。ホーム KPI は会計ホーム（AccountingHome）に現行化。金額・仕訳番号は不変）
>
> **実務上の位置づけ**: 決算の最後は「帳票同士の突合」。複式簿記が正しく運用されていれば、**どの帳票をどこから見ても同じ数字に辿り着く**——試算表の貸借は一致し、BS の資産合計は負債・純資産合計と一致し、PL の当期純利益は BS・株主資本等変動計算書・翌期の繰越利益剰余金のすべてに同じ額で現れる。この「一致の網」を全部確認するのが本章。1 つでも合わなければ、どこかの処理にバグか操作ミスがある。
>
> **前提**: 00〜08 の基本シナリオをすべて完了していること（第 18 期・全 41 仕訳・繰越済み）。
> **使用ユーザー**: soumu_bucho（総務部 部長 山田太郎・経理。財務帳票は会計（Accounting）ワークスペースの【財務帳票】グループ＝経理のみ。資金繰り予測だけは経営管理（ManagementFull）——9-9 参照）。

### ステップ 9-2: 貸借対照表（BS）—— 財政状態と検算行

- **操作する画面**: 【財務帳票】貸借対照表（対象年度「第18期」で検索。未選択でも現在年度に自動解決）

### ステップ 9-7: 消費税集計表

- **この業務の目的（実務解説）**: 消費税申告の基礎資料。税区分別に課税標準（本体）と税額を集計する。
- **操作する画面**: 【財務帳票】消費税集計表（対象年度「第18期」）
- **期待される結果**:

  | 税区分 | 課税種別 | 本体金額 | 消費税額 |
  |---|---|---:|---:|
  | 課税売上 10% | 課税売上 | 3,545,000 | 344,500 |
  | 非課税売上 | 非課税売上 | 500 | 0 |
  | 課税仕入 10% | 課税仕入 | 1,063,026 | 102,126 |
  | 課税仕入 10%(経過措置) | 課税仕入 | 10,200 | 800 |
  | 非課税仕入 | 非課税仕入 | 82,500 | 0 |
  | 不課税 | 不課税 | 3,000,000 | 0 |
  | 対象外 | 対象外 | 208,125 | 0 |

  - **読み方の注意（仕様理解）**:
    1. 課税売上の本体 3,545,000 には**年額前受の 1,200,000**（税は前受計上時に全額発生する）と、**按分振替 No.4 の売上化 100,000**（科目既定の税区分が付くが税額 0）が含まれる。売上高 2,345,000 とは意図的に一致しない。
    2. 課税仕入には**赤黒訂正の両建て**（会議費 5,000×2 と税 500×2）に加え、**償却仕訳 No.38 の貸方 工具器具備品 28,125**（資産科目の既定税区分=課税仕入のまま・税額 0）が積み上がっている（集計は貸借符号を持たない単純合計）。**納税額の確定は必ず試算表の仮受・仮払「残高」で行う**こと（08_決算 ステップ 8-5 でそうした）。

| 記帳 | 04_会計コア | 複式簿記・消費税（内税/外税/非課税/経過措置） |

| 管理会計 | 06_案件・経営管理 | 原価配賦・案件損益・予実管理 |
| 訂正・異常系 | 07_特殊取引 | 赤黒訂正・貸倒れ・債権消込 |
