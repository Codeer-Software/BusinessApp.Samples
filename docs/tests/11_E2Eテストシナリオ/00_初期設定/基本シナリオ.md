# 00_初期設定 基本シナリオ（seed の確認・期首残高・予算・権限の境界）

> 改訂: 2026-07-19（ロール別ページフレーム再編 ADR-0028 に追随）／ **更新: 2026-08-02（部品アーキテクチャ再編 ADR-0040/0041 反映。画面表記は README §2.3 のワークスペース方式。マスタ確認の操作者・画面を現行化し、部門種別・部門メンバーの確認と kaihatsu1_kacho1 の営業部兼務行の登録を追加。登録するマスタのデータ値は不変）**
> **実務上の位置づけ**: 会計ソフト導入時に一度だけ行う「帳簿の器づくり」。制度の器（科目・税・期間・組織・承認ルート）は DDL seed で整備済みなので、本章では①それらを**理解しながら確認**し、②導入時に必ず人手で行う **期首残高の投入** と **予算登録**（および**兼務行の登録**）を行い、③**権限の境界**（部門メンバーシップ×システム管理者フラグ）を体験する。
> ここで押さえる設計思想は 2 つ——「**組織・承認ガバナンスはシステム管理者、業務・会計マスタは経理**」（ADR-0041。旧「制度マスタはシステム管理者」〔ADR-0018〕から 2026-08-02 に転換）と「**帳簿は仕訳と期首残高だけから導出される**」。
>
> **使用ユーザー**: admin（システム管理者）／soumu_bucho（経理）／確認で kaihatsu1_ippan・eigyo_kacho1・kaihatsu1_kacho1・kaihatsu1_bucho。

### ステップ 0-10: 期首残高の投入（複式簿記の入口）

- **この業務の目的（実務解説）**: 導入時点の財産・債務を新しい帳簿の出発点として引き継ぐ。**借方合計＝貸方合計（Σ=0）でなければ帳簿は始められない**——アプリは合計が 0 でないと赤字表示で警告する。
- **操作する画面**: Accounting >【設定】会計年度 > 第18期（soumu_bucho）
- **具体的な操作手順**:
  1. 第18期を開き、期首残高リストに 6 行を追加:
     | 勘定科目 | 残高（借方正・貸方負） |
     |---|---|
     | 現金 | 100,000 |
     | 小口現金 | 50,000 |
     | 普通預金 | 5,000,000 |
     | 敷金保証金 | 600,000 |
     | 資本金 | **-5,000,000** |
     | 繰越利益剰余金 | **-750,000** |
  2. **わざと繰越利益剰余金を `-700,000` にしてみる** → 期首残高合計が `50,000` と**赤色表示**になることを確認 → `-750,000` に直して合計 0 → 登録。
- **期待される結果**:
  - **直接的な結果**: 保存成功・合計 0。
  - **波及する結果**: 仕訳ゼロでも帳票が動く——【財務帳票】合計残高試算表 の繰越残高列（借方計=貸方計= 5,750,000）、同 貸借対照表（資産合計 5,750,000 = 負債・純資産合計）、【帳簿】出納帳の繰越残高、AccountingHome の経営サマリの現預金 5,150,000 円。**期首残高は仕訳と並ぶ帳票導出のもう一つの源泉**。
