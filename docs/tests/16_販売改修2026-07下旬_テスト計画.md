### 0.2 新機能の検証観点

- 単位: 入力→変換コピー（見積→受注→請求書）→帳票出力の全経路で値が保持される
- 部門: 既定値（作成者所属）→伝票間コピー→売上仕訳の明細部門→帳簿（総勘定元帳の部門絞り込み）で回収できる
- 確定フロー: 権限マトリクス（下表）どおりに UI が出し分けられ、実行対象が「確定済かつ有効」に限定される
- 変換: 見積の状態遷移（accepted 化）・二重変換ガード・下書き契約の初期値
- 検索: 各条件の絞り込み結果が SQL 的に正しい（0件・複合条件も）
