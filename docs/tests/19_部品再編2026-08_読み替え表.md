## 1. ロール → 権限の読み替え

旧「ロール」列は廃止。権限は部門メンバーマスタ＋管理者フラグから導出される（ADR-0041）。

| 旧ロール | 新モデルでの状態 | 代表アカウント（パスワード同名） |
|---|---|---|
| general（一般社員） | どこかの部門の「一般」メンバー | kaihatsu1_ippan（開発）・eigyo_ippan（営業） |
| approver（承認者） | どこかの部門の「課長/部長」メンバー | kaihatsu1_bucho・kaihatsu1_kacho1 |
| accounting（経理） | 経理種別部門（総務部）のメンバー | soumu_bucho・soumu_ippan |
| sysadmin | is_sysadmin フラグ（業務フレームには入れない！） | admin |

**重要な挙動変更**:
- 開発部の一般・承認者は**営業業務（見積・受注・検収等）が見えなくなった**（営業種別部門のメンバーのみ）。
  旧シナリオで kaihatsu1_ippan が見積を作る手順は **eigyo_ippan に読み替える**
- admin は業務画面に入れない。**業務系の手順はすべて soumu_bucho（経理）で実施**する
- 承認ルート・承認 OR 並列・受信箱の挙動は不変（ADR-0016/0023 の機構をそのまま継承）

## 2. フレーム URL の読み替え

| 旧 URL | 新 URL |
|---|---|
| /General/Home | /ExpenseStaff/Top（経費）・/Timesheet/Top（工数）・/SalesStaff/Top（営業） |
| /Approver/Home | /ExpenseApprover/Top ほか（承認待ちは ExpenseApprover） |
| /Accounting/Home | /Accounting/Top（会計）— ただし内容は下記「メニュー配置」参照 |
| /Sysadmin/Home | /MasterAdmin/Top |

## 3. メニュー配置の読み替え（旧 経理/Sysadmin フレームの 3 階層 → 部品ワークスペース）

| 旧配置（Accounting/Sysadmin フレーム） | 新ワークスペース |
|---|---|
| 一般業務/経費精算/*（申請・承認待ち・精算処理待ち・通知） | ExpenseAccounting（経費精算） |
| 一般業務/販売/*（見積〜請求書・入金・定期請求・SES） | SalesBilling（営業業務） |
| 一般業務/購買/*（仕入先請求書・支払予定表・振込データ） | Purchasing（購買・支払） |
| 会計/仕訳・帳簿・銀行・設定（会計年度） | Accounting（会計） |
| 財務・経営/財務帳票/*（試算表〜消費税集計） | Accounting の「財務帳票」グループ |
| 財務・経営/財務帳票/資金繰り予測 | **ManagementFull（経営管理）へ移動** |
| 財務・経営/予算/* | ManagementApprover（承認者）／ManagementFull（経理） |
| 財務・経営/案件/*（工数入力・工数管理・人件費・案件損益） | 工数入力/管理→TimesheetAccounting、人件費・案件損益→ManagementFull |
| マスタ/*（取引先・案件・口座） | MasterBusiness（業務マスタ） |
| システム管理/会計マスタ・税制（費目・科目・税率ほか） | **MasterBusiness（経理管轄へ移管）** |
| システム管理/組織・承認（ユーザー・部門・テンプレ・ルート判定） | MasterAdmin（sysadmin のみ） |

ワークスペース間の移動: 経理系はサイドバー「ほかの業務」（静的リンク）、一般・承認者は
「ほかの業務/マイページ」またはホーム画面のボタン（権限に応じて動的に出る）。

## 4. ホーム画面の読み替え

- 旧 Home（全ロール共通ダッシュボード）は廃止 → ExpenseHome（やること・通知・切替ボタン）／
  SalesHome（ショートカット・切替）／AccountingHome（未処理・当月 KPI）
- 旧 Home の「仕入先請求書の期限アラート」→ Purchasing の支払予定表で確認
- 旧 Home の「資金繰りアラート」→ ManagementFull の資金繰り予測で確認
- 旧 Home のショートカット群 → 各部品のサイドバー／ホームのボタン
