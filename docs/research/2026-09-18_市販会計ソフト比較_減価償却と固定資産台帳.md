# 市販会計ソフト比較 — 減価償却の計算と固定資産台帳の所在

> **[06_利用者の作業](../06_利用者の作業.md) の W-38（減価償却を計算して計上する）を「必須」に数えるか**を決める材料として、
> 市販の会計ソフトが減価償却の計算と固定資産台帳を**会計ソフト本体の機能として持っているか、別製品か**を当たった
> （開発者の依頼。2026-09-18。「2026 年最新の状況をリサーチしてほしい。多数の会計ソフトは減価償却の計算機能を持っているんじゃないでしょうか」）。
> **持つかどうかは既に決まっている**——[ADR-0007](../decisions/0007-会計コアの機能スコープ.md)「計算機能を持つのは減価償却のみ」、[03 §E](../03_機能スコープ.md) の ○。
> 本書は**調べた事実だけ**を持ち、判断は [05 の Q-39](../05_開発者への問い.md) と 06 が持つ（[32 §4](../32_調査のルール.md)）。
>
> **結論を先に書く。6 社で割れた**——
> **3 社（弥生会計・freee 会計・マネーフォワード クラウド会計）は会計ソフト本体が固定資産台帳と減価償却の計算を持つ**（§1）。
> **3 社（PCA・勘定奉行クラウド・TKC）は別製品**で、償却の仕訳を会計へ連携する形である（§2）。
> **本体に持つ 3 社でも差がある**——freee と弥生会計 Next は本体で月次にでき自動で仕訳を起こす。マネーフォワードは年 1 回だけで、計算は「参考値」を見て利用者が今期償却額を入力し、月次は別製品（§1-3）。
> **どの社がどの規模の会社向けかは、本書では分けていない**（各社の対象の記述を取っていない）。ペルソナへの当てはめは [05 の Q-39](../05_開発者への問い.md) が Claude の判断として持つ。

## 0. どこまで調べたか

**一次情報に当たったのは 6 社**（弥生・freee・マネーフォワード・PCA・OBC・TKC）。**6 社の外は当たっていない**（ミロク・JDL・ソリマチなど）。
**すべて各社の公式ドメインのページ**（サポート・ヘルプ・製品・料金）で、比較サイトや記事は 1 つも根拠にしていない。

**写し方は社ごとに違う**（[32 §3](../32_調査のルール.md)）。

- **弥生・マネーフォワード・PCA・OBC は、素の `curl` で生の HTML を取り、逐語を機械で抜き出した**（2026-09-18）

  （`/api/v2/help_center/ja/articles/<id>.json`）が返す記事本文（`body`）と `updated_at` から写した。
  **ブラウザ表示と同じ本文かは突き合わせていない**。freee の製品・料金ページ（www.freee.co.jp）は素の `curl` で取れた

  OBC と PCA は HTTP の `Last-Modified` しか無く、**弥生は日付の手がかりが無い**（HTTP ヘッダにも無い）

## 1. 会計ソフト本体が持つ 3 社

### 1-1. 弥生会計（デスクトップ 26・Next）

- **弥生会計 26（デスクトップ）は本体の機能**——「［拡張機能］メニューから［固定資産管理］を選択」（Y4）。
  比較表（Y1）は「固定資産管理」「固定資産台帳」「減価償却費の計算」の行で、**スタンダード・プロフェッショナル・ネットワークの 3 グレードとも「対象」**（画像の `alt` 属性の字）
- できること（Y4 の逐語）: 「減価償却費の自動計算」「固定資産（一括償却資産を含む）に関する資料の作成」「償却仕訳や除却損仕訳の作成」「固定資産データの次年度への繰り越し」
- 償却方法（Y5）: 「定額法」「定率法」（200%・250%・旧）「均等償却」「一括償却」「即時償却」（「少額減価償却資産（40万円未満※）」。「※取得価額の上限：2026年3月31日以前の取得分は「30万円未満」、4月1日以降の取得分は「40万円未満」に引き上げられました」）「任意償却」「非減価償却資産」
- **仕訳は自動ではなく「仕訳書出」の操作で振替伝票へ書き出す**（Y4「償却仕訳を振替伝票へ書き出します」、Y7「［固定資産一覧］に登録している資産について、減価償却や除却損に関する仕訳を書き出します。」）。月次も選べる（Y7「月次で償却する」）。
  **書き出せない仕訳が 3 つ**——「固定資産取得の仕訳」「一括償却資産の仕訳」「売却の仕訳」（Y7）
- **弥生会計 オンラインは新規申し込みを終了**し、後継の**弥生会計 Next も本体に固定資産台帳を持つ**——機能一覧の「決算」区画に「固定資産台帳」（Y17）、
  「減価償却費の自動計算と仕訳作成」「除却や売却などの仕訳を自動作成」「減価償却費の計算単位（決算期（年次償却）・毎月（月次償却））」（Y19）。
  **料金プランの比較表に固定資産台帳の行は無い**ので、どのプランから使えるかは原文から決まらない（§4）

### 1-2. freee 会計

- **本体の機能。法人の新プラン 5 つ（ひとり法人／スターター／スタンダード／アドバンス／エンタープライズ）すべてで「固定資産台帳」「固定資産台帳（除却・売却）」が ○**（F9 のプラン別機能表）
- 「固定資産台帳へ登録された資産は、自動で減価償却費の計算と減価償却費の仕訳登録が行われます。また、この固定資産台帳は、法人税申告書の別表16(1)や別表16(2)を作成する際の元情報にもなります。」（F1）
- 償却方法（F4）: 「少額償却」「一括償却」「定額法」「定率法」「旧定率法」「旧定額法」「償却なし」「任意償却」「即時償却」「均等償却」
- **月次**: 「「月次償却」の項目を［する］に変更して保存すると、減価償却の仕訳が月次単位で発生するようになります。」（F1）
- **除却・売却**: 除却は台帳から登録し「除却の仕訳を作成する」で除却仕訳が自動計上（F6）。売却は「2022年3月からは…固定資産の「売却」機能が標準搭載」（F7）
- **別プロダクト「freee固定資産」がある**——「freee固定資産は、「freee会計の固定資産台帳」とは別のプロダクトです。」「freee会計の固定資産台帳は将来的には提供を終了し、新サービス「freee固定資産」に完全移行する予定です。」
  その基本機能は「無料（会計付帯）。デフォルト1,000件まで。freee会計ユーザーに標準付帯されます。」（F11）。**移行後にどう付帯するかは原文に無い**

### 1-3. マネーフォワード クラウド会計

- **本体に固定資産台帳がある**——「「固定資産台帳」画面では、取得・購入した固定資産を登録することで、登録した内容をもとに減価償却費の計算や仕訳登録が可能です。」（M1）。
  プラン別機能表（M3）に固定資産台帳の行は無く、同ページは「以下の表に記載されていないクラウド会計の機能は、ご契約中のプランに関わらず利用可能です。」と書く
- **年 1 回だけ**——「マネーフォワード クラウド会計・確定申告では、1年ごとに減価償却費を計上できます。」（M1）「減価償却費を月ごとに自動計上することはできません。」（M2）
- **計算は「参考値」で、登録時は参考値を見て今期償却額を入力し、繰越後は確認して保存する**——「「今期償却額」欄の上部には…参考値が表示されます。表示された参考値を確認し、金額を入力してください。」「「改定取得価額」は自動入力されません。自身で手計算した値を入力してください。」（M1）
- **月次は別サービス「マネーフォワード クラウド固定資産」**（「月ごとに減価償却費を計上したり、償却資産申告を行うことが可能」M1）。料金は個別見積（M8「詳しくはお問い合わせください」）。
  **そのクラウド固定資産は「マネーフォワード クラウド会計」に仕訳を連携できず**（M15）、連携先は「『マネーフォワード クラウド会計Plus』やNetsuite」（M8）。クラウド会計へは仕訳ファイルをエクスポートして仕訳帳へインポートする（M15）

## 2. 別製品にしている 3 社

### 2-1. PCA
