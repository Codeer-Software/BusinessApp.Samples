# 適格請求書発行事業者の登録の効力を失う日

## 調査の目的

計上時に明細へ写す登録番号を、`journal_lines.tax_point`（課税仕入れを行った日）で引く
（[13 §4](../13_取引先設計.md)）。そのとき、**公表システムが出す「登録取消年月日」「登録失効年月日」が
効力の最終日なのか、効力を失った初日なのか**が決まらないと、境界の 1 日で引く結果が変わる。

[14 §2](../14_適格請求書発行事業者の登録.md) はこの論点を**フェーズ 3 送り**と決めていたが、
写しを実装する段になって「境界日をどちらに倒すか」を決める必要が出たので、当たれるだけ当たった。

## 確認できたこと

### 登録の取りやめ（届出による）は「翌課税期間の初日」から効力を失う

「適格請求書発行事業者の登録の取消しを求める旨の届出書」を提出した場合、
**その課税期間の翌課税期間の初日**から登録の効力が失われる。
届出が翌課税期間の初日から起算して 15 日前の日までに提出されなかったときは、
**そのさらに翌課税期間の初日**から失われる。

- 出典: [国税庁 D1-70 適格請求書発行事業者の登録の取消しを求める旨の届出手続](https://www.nta.go.jp/taxes/tetsuzuki/shinsei/annai/hojin/annai/invoice_07.htm)（確認日 2026-08-26）
- 出典: [国税庁 消費税の仕入税額控除制度における適格請求書等保存方式に関する Q&A 問 13（登録の取りやめ）](https://www.nta.go.jp/taxes/shiraberu/zeimokubetsu/shohi/keigenzeiritsu/pdf/qa/13.pdf)（確認日 2026-08-26）

### 公表サイトが公表するのは「登録年月日・失効年月日・取消年月日」の 3 つ

公表サイトの運営方針が、公表項目として**②登録番号 ③登録年月日、失効年月日、取消年月日**を挙げている。
登録の取消（消税法 57 の 2 ⑥。**2026-08-26 の初版は ⑧ と書いていたが、2026-09-19 に e-Gov の現行版で ⑥ が税務署長による取消し、⑧ は登録簿の変更の届出と確かめて直した**）または登録の失効（消税法 57 の 2 ⑩・57 の 3）に該当した場合に公表情報を更新し、
**取消・失効の後 7 年間はその年月日を掲載し、7 年経過後に削除する**。

死亡の場合、届出の提出が無くても**死亡した日の翌日から 4 月を経過した日**に失効する。

- 出典: [適格請求書発行事業者公表サイトの運営方針（令和 5 年 1 月改訂）](https://www.invoice-kohyo.nta.go.jp/files/invoice-houshin.pdf)（確認日 2026-08-26）

## 確認できなかったこと（重要）

**公表される「登録取消年月日」「登録失効年月日」が、その日を含めて有効なのか、
その日から無効なのかを明示した一次情報は見つからなかった。**

- 上の制度説明は「**翌課税期間の初日から**効力を失う」「**4 月を経過した日に**失効する」と、
  いずれも**効力を失う側の日**を指す書き方をしている。これを素直に読むと、
  公表される日付も「効力を失った初日」である可能性が高い
- ただし**運営方針・インボイスQ&A のどちらも、公表項目としての日付の定義を書いていない**。
  リソース定義書（[2026-08-25 のリサーチ §3-2](2026-08-25_取引先の識別番号と公表システム.md)）にも
  項目名しかない
- **推測で決めない**（[32_調査のルール](../32_調査のルール.md)）。実データを取り込むフェーズ 6 で、
  取消・失効のある事業者を実際に引いて確かめる

## 2026-09-19 開発者の確認——失効年月日・取消年月日は「効力がなくなる最初の日」

**開発者の決定（2026-09-19）**——「取消・失効年月日の当日から適格請求書発行事業者でなくなる、解釈で行きましょう」。
**根拠として示された条文と Q&A は次のとおり**（逐語は開発者提示）。**消税法 57 の 2 ⑩ は、2026-09-19 に Claude が e-Gov 法令 API で現行版を取り、開発者提示の字と一致することを確かめた**
（令和8年4月1日施行版 `363AC0000000108_20260401_506AC0000000008`。URL https://laws.e-gov.go.jp/law/363AC0000000108 。確認日 2026-09-19）。
**問 13 は上の「確認できたこと」で 2026-08-26 に Claude が開いた版（`.../pdf/qa/13.pdf`）がある**。開発者が引いたのは「令和6年4月改訂」の問で、現行版と同文かは未確認。

**開発者の言葉（2026-09-19）**——

> 失効日という用語は法令によってその使われ方が異なり、「有効期間の満了日（その日の24時まで有効）」を指す場合と「効力がなくなる最初の日（満了日の翌日）」を指す場合があり、法令によって検討が必要です。

**消税法 57 の 2 ⑩**（開発者提示の逐語。①〜⑨・⑪・⑫は略）——

```text
１０　適格請求書発行事業者が、次の各号に掲げる場合に該当することとなつた場合には、当該各号に定める日に、第一項の登録は、その効力を失う。
一　当該適格請求書発行事業者が第一項の登録の取消しを求める旨の届出書をその納税地を所轄する税務署長に提出した場合　その提出があつた日の属する課税期間の末日の翌日（その提出が政令で定める日の翌日から当該課税期間の末日までの間にされた場合には、当該課税期間の翌課税期間の末日の翌日）
二　当該適格請求書発行事業者が事業を廃止した場合（前条第一項の規定により同項第三号に掲げる場合に該当することとなつた旨を記載した届出書を提出した場合に限る。）　事業を廃止した日の翌日
三　当該適格請求書発行事業者である法人が合併により消滅した場合（前条第一項の規定により同項第五号に掲げる場合に該当することとなつた旨を記載した届出書を提出した場合に限る。）　当該法人が合併により消滅した日
```

**開発者の読み**——同項 二 は、事業を廃止した日の翌日に効力を失うとしている。廃止した当日は有効で、翌日は無効と読むのが自然である（翌日まで発行可能と読むのは明らかに不自然）。
同項 一 については**インボイスQ&A 問 13**（令和6年4月改訂。開発者提示の逐語）が「翌課税期間の初日に登録の効力が失われる」と説明しており、同日以降は適格請求書発行事業者でなくなることが示されている。
**以上より、適格請求書発行事業者の登録については、失効年月日とは「効力がなくなる最初の日」であると解釈するのが妥当。**

**未確認のまま残るもの**——**税務署長による登録の取消し（消税法 57 の 2 ⑥）の効力の日は、条文に無い**——2026-09-19 に Claude が同じ版の ⑥ を読んだが、⑥ は取り消せる事実を列挙して「登録を取り消すことができる」と言うだけで、いつから効力を失うかは書いていない（開発者の決定は取消・失効の両方を「当日から」としており、示された根拠は失効（⑩）と届出による取りやめ（問 13）である。取消しの効力の日を定める条文・通達は未確認）。公表システムの「取消年月日」「失効年月日」の項目が、この条文の「効力を失う日」そのものを載せているか（項目の定義は上の「確認できなかったこと」のとおり書かれていない）。**フェーズ 6 の取込で実データを見る**。

## 実装でどうしたか（2026-08-26）

**境界の日を含める側に倒した**（`ended_on == tax_point` の登録も引く）。**2026-09-19 に制度の解釈が「含めない」と決まった**（上）。**直すのはフェーズ 3**（[14 の保留リスト](../14_適格請求書発行事業者の登録.md)）。
理由は [14 §6](../14_適格請求書発行事業者の登録.md) に書いた——ここは**根拠の記録であって制度上の判定ではない**ので、
境界の 1 日で番号を落とすほうが害が大きい（計上済みは不変なので後から補えない）。
番号が残っていれば、解釈が決まったときに読み替えられる。

**この選択は税額計算に影響しない。** 税額計算を支配するのは利用者が選んだ税区分であり、
相手の登録状況ではない（[ADR-0018](../decisions/0018-帳簿の記載事項は計上時に写して固定する.md)）。
