# 税制・会計制度リサーチ（2026年7月5日時点）

> 本アプリの設計判断の前提となる、実装時点の税制・会計制度の調査記録。
> **制度は毎年変わる**前提で、税率・区分・閾値はすべてマスタ化する（ハードコード禁止）。
> 次回リサーチ推奨: 令和9年度税制改正大綱公表時（例年12月）、および食料品消費税の法案動向。

## 1. 消費税率（現行・変更予定）

| 区分 | 税率 | 内訳（国税+地方） |
|---|---|---|
| 標準税率 | 10% | 7.8% + 2.2% |
| 軽減税率（飲食料品・新聞） | 8% | 6.24% + 1.76% |

- **要注意（未確定）**: 2026年6月時点で、政府は「**2027年4月から食料品の消費税率を8%→1%に引き下げる（2年間限定）**」案を軸に最終調整中。外食は10%維持の見通し。ゼロ税率はレジ改修期間の問題で見送りの公算。
  → **設計への影響: 税率マスタは「適用開始日・終了日」を持つ期間管理が必須**。1%のような新税率の追加が設定だけでできること。

## 2. インボイス制度（適格請求書等保存方式）

### 2.1 免税事業者等からの仕入れに係る経過措置（令和8年度税制改正で4段階化・2年延長）

改正前の「80%→50%→終了」から、**「8・7・5・3割控除」の4段階**に緩和された。

| 期間 | 控除割合 |
|---|---|
| 2023-10-01 〜 2026-09-30 | 80% |
| 2026-10-01 〜 2028-09-30 | **70%** ← 直近の切替（あと3ヶ月） |
| 2028-10-01 〜 2030-09-30 | 50% |
| 2030-10-01 〜 2031-09-30 | 30% |
| 2031-10-01 以降 | 控除なし |

- **新設の制限**: 同一の免税事業者等からの課税仕入れが**年1億円を超える部分**は経過措置の対象外（改正前は10億円）。
- → **設計への影響: 経過措置控除割合は期間付きマスタで持つ。免税事業者からの仕入は税区分で区別**（例:「課仕入10%（経過措置）」）。本アプリのリリースデモ時期は 70% 期間に当たる。
- 出典: [freee（7・5・3割控除の解説・改正後スケジュール）](https://www.freee.co.jp/kb/kb-invoice/invoice_transitional_measures/) / [国税庁 令和8年度税制改正特集](https://www.nta.go.jp/taxes/shiraberu/zeimokubetsu/shohi/keigenzeiritsu/invoice-review/index.htm) / [TCNB](https://www.tc-nb.co.jp/2155/) / [インフォマート](https://www.infomart.co.jp/seikyu/column/invoice-system_keikasochi)

### 2.2 2割特例・3割特例（小規模事業者の納税額軽減）

- 2割特例（売上税額の2割納付）は **2026-09-30 を含む課税期間で終了**。
- 令和8年度税制改正で**個人事業者のみ**「3割特例」（令和9・10年分）が新設。**法人への延長は見送り**。
- → ペルソナ（従業員30〜80名の課税事業者法人）には直接適用なし。ただし取引先（フリーランス外注）の登録判断に影響する背景知識。
- 出典: [国税庁 2割特例](https://www.nta.go.jp/publication/pamph/shohi/kaisei/202304/01.htm) / [MONEYIZM](https://www.all-senmonka.jp/moneyizm/management/314425/) / [フリーランス協会](https://blog.freelance-jp.org/20251217-24616/)

### 2.3 その他

- 適格請求書発行事業者の登録番号は「T+13桁」。国税庁公表システムの Web-API で実在照合可能（フェーズCで利用予定。API仕様は実装時に再調査）。

## 3. 電子帳簿保存法

- 電子取引データの電子保存は **2024-01-01 から完全義務化**（紙出力保存は不可）。
- 要件は「真実性」（タイムスタンプ or 訂正削除防止の事務処理規程等）と「可視性」（**日付・金額・取引先で検索可能**であること）。
- 2026年は税務調査で運用の厳格チェックが進む傾向。
- → **設計への影響**: 本アプリは「完全準拠（JIIMA認証相当）」は**目指さない**（機能スコープで見送り明記）。ただし証憑ファイル添付＋日付・金額・取引先による検索性は備え、「対応の土台がある」ことを訴求点にする。
- 出典: [国税庁 電子帳簿等保存制度特設サイト](https://www.nta.go.jp/law/joho-zeikaishaku/sonota/jirei/tokusetsu/index.htm) / [クラウドサイン](https://www.cloudsign.jp/media/electronic-books-maintenance-act/) / [OBC](https://www.obc.co.jp/360/list/post189)

## 4. 減価償却・少額資産（令和8年度税制改正で拡充）

| 取得価額 | 扱い |
|---|---|
| 10万円未満 | 消耗品費等で全額損金（資産計上不要） |
| 10万円以上20万円未満 | 一括償却資産（3年均等償却）も選択可 |
| **40万円未満**（改正前30万円） | 中小企業者等の少額減価償却資産特例で即時償却（**2026-04-01以後取得分**から。年合計300万円まで、従業員400人以下、期限 2029-03-31） |
| それ以上 | 通常償却（定額法／200%定率法） |

- → **設計への影響**: 閾値（10万/20万/40万/年300万）はすべて期間付きマスタ化。固定資産台帳は償却方法（定額/定率/一括/即時）を持つ。
- 出典: [国税庁 No.5408](https://www.nta.go.jp/taxes/shiraberu/taxanswer/hojin/5408.htm) / [財務省 令和8年度税制改正大綱](https://www.mof.go.jp/tax_policy/tax_reform/outline/fy2026/08taikou_03.htm) / [経理ドリブン](https://keiridriven.mjs.co.jp/180803/) / [弥生](https://www.yayoi-kk.co.jp/lawinfo/detail.20260407/)

## 5. 法人税（参考: 決算関連の背景知識）

- 中小法人の軽減税率: 所得年800万円以下の部分 **15%**（本則19%）。令和7年度改正で **2027-03-31 までに開始する事業年度**まで延長。所得10億円超の事業年度は17%。
- 本アプリのスコープ: 法人税**申告書の作成は対象外**。決算整理仕訳（未払法人税等の計上）を支援する範囲。
- 出典: [山田&パートナーズ](https://www.yamada-partners.jp/reform/r7/h01-extension-of-reduced-tax-rates-for-small-and-medium-sized-enterprises) / [東京法人会連合会](https://www.tohoren.or.jp/taxinfo/2025022021653.html)

## 6. 収益認識（ペルソナの売上計上に直結）

- 「収益認識に関する会計基準」（企業会計基準第29号）は上場企業・大会社（会社法監査対象）に強制適用。**非上場の中小企業は適用任意**で、従来どおり企業会計原則等（検収基準・出荷基準等）による処理が認められる。
- → **設計への影響**: ペルソナは非上場中小 → **受託開発は検収基準**、**SaaS 月額は役務提供期間で按分（前受金・繰延処理）**、SES/準委任は稼働月の役務完了で計上、という実務的な組み合わせで設計する。新基準のフル実装（履行義務の識別等）はスコープ外。
- 出典: [freee](https://www.freee.co.jp/kb/kb-ipo/recognize_revenue/) / [マネーフォワード](https://biz.moneyforward.com/accounting/basic/65017/) / [弥生](https://www.yayoi-kk.co.jp/kaikei/oyakudachi/shinshuekininshikikijun/)

## 7. 設計への反映まとめ（マスタ化必須リスト）

| 項目 | 持ち方 |
|---|---|
| 消費税率（10%/8%/将来の1%等） | 税率マスタ（適用開始日・終了日） |
| 税区分（課税/非課税/不課税/免税/経過措置） | 税区分マスタ（税率参照・控除割合参照） |
| インボイス経過措置控除割合（80/70/50/30%） | 期間付き控除割合マスタ |
| 少額資産の閾値（10/20/40万・年300万） | 制度閾値マスタ（期間付き） |
| 勘定科目・補助科目 | 科目マスタ（ユーザー編集可） |
| 償却方法・耐用年数 | 固定資産マスタの属性 |
