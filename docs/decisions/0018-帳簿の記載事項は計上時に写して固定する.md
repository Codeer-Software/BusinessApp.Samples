# ADR-0018 帳簿の記載事項は計上時に写して固定し、制度上の資格は有効期間で持つ

## 状況

仕訳帳を作ったところ、**取引先名が現在のマスタ名で表示されていた**。
`journal_lines.partner_name_snapshot` という写しの列は最初からあるのに、
**そこへ書き込む経路がどこにも無く、常に NULL** だった（2026-08-25 の自己レビュー）。

取引先が改名すると、過去の帳簿の記載が遡って変わる。
消法 30 ⑧が帳簿に求める「課税仕入れの相手方の氏名又は名称」が、
記帳したときの名前でなくなるということである。

同じ「過去を固定する」問題が**適格請求書発行事業者の登録**にもあり、
[docs/06 §1](../06_消費税設計.md) で保留になっていた。**2 つを同じ規則で扱えるかを決める。**

## 決定

### 帳簿の記載事項は「計上時に写して固定する」。制度上の資格は「有効期間で持つ」

**2 つは別物として扱う。**

| | 帳簿の記載事項 | 制度上の資格 |
|---|---|---|
| 例 | 取引先の名称・資産又は役務の内容・住所 | 適格請求書発行事業者の登録・登録番号 |
| 性質 | **その時点でどう記帳したか** | **いつからいつまで、どういう状態だったか** |
| 持ち方 | **仕訳明細に写す**（計上時に確定） | **有効期間つきのマスタ**（`partner_invoice_registrations`） |
| 根拠 | 消法 30 ⑧。記帳した内容が後から変わってはいけない | 登録は取消・失効しうる。1 列では「その時点の状態」を表せない |

**登録番号は帳簿の法定記載事項ではない**（消法 30 ⑧。国税庁 Q&A が「相手方の登録番号の記載は不要」と明記）。
登録番号は**適格請求書＝相手が発行する書類**の記載事項であり（消法 57 の 4 ①）、
買手はその書類を保存する。会計ソフトが登録状況を持つのは、
**税額計算の判定と入力支援のため**であって、帳簿へ記載するためではない。

### 写しは計上のときに、サーバが書く

1. **焼き込むのは計上時**（下書き保存時ではない）。下書きのうちは取引先を変えられるので、
   確定するのは計上の瞬間が自然である
2. **利用者に入力させない。** 画面に写しを出すと任意の名前を書けてしまい、
   法定記載事項の信頼性が落ちる。サーバがマスタから引いて書く
3. **伝票の取引先を使う明細にも焼き込む。** 帳簿は「明細 → 伝票」の順で取引先を見るので
   （[docs/04 §4-1](../04_会計ドメイン設計.md)）、明細に取引先が無い行には
   **伝票の取引先の名称**を写す
4. **取消・訂正は原仕訳の写しをそのまま引き継ぐ。** 反対仕訳は過去の反転であって、
   新しい記帳ではない（既にそうなっている）

### 登録状況は「計算の入力」ではない

**税額計算を支配するのは、利用者が選んだ税区分である。**
マスタの登録状況で自動的に控除割合を決めてはならない。

相手が適格請求書発行事業者であっても、**登録番号のない区分記載請求書等しか受け取っていなければ、
一律に経過措置が適用される**（[リサーチ §1-4](../research/2026-08-23_消費税インボイス制度.md)。選択制ではない）。
適用は「受け取った書類」で決まり、「相手の資格」では決まらない。

登録状況の使い道は次の 2 つに限る。

- **入力支援・警告**（「この取引先は当時未登録です。経過措置の税区分ではありませんか？」）
- **判定の根拠の記録**（計上時点の登録番号を明細に写す。帳簿には印字しない）

## 帰結

- `partner_name_snapshot` に書く経路を、計上の関門に作る（次の作業）
- **既に計上済みの仕訳は直さない。** 計上済みは不変（ADR-0004）。
  写しが無い行は帳簿が現在のマスタ名で補う（`COALESCE`）
- ~~`partners` に住所欄が無く、フェーズ 3 で列と写しの両方が要る~~ →
  **その後の決定で写しは作らないことになった**（2026-08-25。開発者の決定）。
  スコープ内で住所が要るのは回収特例の 1 類型だけで、**明細の「内容」欄に書く運用**にする。
  `partners` の所在地の列（`address`）は追加済み。決定の本体は [07 §1-4](../07_取引先設計.md)
- ~~`partner_invoice_registrations`（有効期間つき）はフェーズ 3 で作る~~ →
  **作成済み**（2026-08-25。`Designer/ddl/006_partner_registrations.sql`。列の設計は [07 §3](../07_取引先設計.md)）
- **同じ規則を他の記載事項にも当てる。** 「帳簿に載る値はその時点で写す」「資格や制度値は期間で持つ」
