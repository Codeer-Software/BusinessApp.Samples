# 0008: 売上計上タイミング＝検収基準（請求時計上は採らない）

- 状態: 採用 / 日付: 2026-07-05

## 背景
B-4 請求・入金で「いつ売上仕訳を切るか」を決める必要がある。候補は請求書発行時・検収時・入金時。

## 選択肢
1. **検収確定時に売上計上**（D 売掛金 / C 売上高＋仮受消費税）← 採用
2. 請求書発行時に売上計上
3. 入金時に売上計上（現金主義）

## 決定
選択肢1。`acceptances.status='confirmed'` への確定操作で自動仕訳（source_type='acceptance'）。請求書は検収額を反映した帳票であり会計イベントとしない。入金は売掛金の消込のみ（source_type='receipt'）。

## 根拠
- ペルソナの主業＝受託開発は**役務完了（検収）を充足時点とする収益認識が原則**。請求時計上は締め日と検収日がずれると期間損益を歪める。
- SES は月次検収（稼働報告の承認）として同じ流れに載る。SaaS 月額は v1 では月次検収扱いで統一し、繰延収益の月次按分の厳密化は B'-4 で実装する。
- 現金主義（選択肢3）は発生主義会計に反するため不採用。

## 影響
- 検収確定・入金消込は仕訳を伴うため**経理ロール専用の操作**（B-8 の原則を踏襲）。
- 期末の売掛金残高＝検収済み未入金。売掛管理一覧・資金繰り予測（C-2）の基礎データになる。
- 値引き・過入金・手数料差引の消込差額処理は v1 見送り（バックログ）。
