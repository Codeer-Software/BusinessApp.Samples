# ADR-0020: メニュー再構成（フレーム直列化）とマスタの確認ページ分離

- 日付: 2026-07-11
- 状態: 採用・実装済み（実機確認済み）
- 関連: ADR-0019（ページフレーム分割）、docs/12 FB-010・FB-024

## 背景（ユーザーレビュー 2026-07-11）

ADR-0019 の 6 フレーム分割後のレビューで 5 点の指摘を受けた:

1. Main サイドバーに「経費精算・工数入力」（画面）と「業務メニュー配下のフレーム入口」が同居し、**項目の抽象度が揃っていない**
2. その帰結として「業務メニュー」という中間階層も不要
3. 経費申請の検索条件で件名・利用日の入力欄が数文字で文字切れ
4. 閲覧できるが編集できないマスタ（取引先・案件）で「新規作成」ボタンが押せてしまい困惑する
5. Logout が通常メニューと同列で誤クリックしやすい・確認が無い

さらに 4 について追加の方針指示: **「マスタを直接見せる必要はない。案件一覧を見せたいなら閲覧専用の確認ページを作り、マスタ（編集画面）自体は編集も閲覧もできなくする方が健全」**。

## 決定

### 1. Main サイドバー = フレーム入口のみ（抽象度の統一）

- サイドバーは「ホーム＋5 フレーム入口（販売管理・購買管理・会計・経営管理・システム管理）＋Logout」のみ。「業務メニュー」階層は廃止しトップレベルに直列。
- 経費精算（申請/申請中/承認待ち/通知）と工数入力は**ホームのショートカットボタン**へ移設（「よく使う機能はショートカット」という役割分担）。承認待ちは承認者・経理・sysadmin のみ表示し、ロール依存ボタンは行の右側に寄せて非表示時の空白が目立たない並びにする。
- 各モジュールは Main の OtherPageModuleDesigns に登録して **URL 互換を維持**（/Main/ExpenseRequest 等は不変。通知リンク・スクリプト遷移も無改修）。

### 2. マスタは「編集画面」と「確認ページ」を分離（画面到達と読取権限の分離）

- **編集画面**（Partner / Project）: 会計フレームの「マスタ/取引先」「マスタ/案件」へ移設。会計フレームは経理・sysadmin 専用なので、他ロールは**画面ごと到達不能**（直 URL もフレームゲートでブロック）。
- **確認ページ**（PartnerView / ProjectView）: 販売管理フレームに「取引先一覧」「案件一覧」として全ロール向けに配置。検索可・新規作成/削除/詳細遷移なしの一覧専用モジュール（CanCreate/Update/Delete=false・DetailLayouts 空＝CommonMistakes #68 のパターン）。
- **モジュールのデータ読取権限は全員のまま**——見積の取引先セレクト等の参照を壊さないため（ADR-0019 の教訓）。「どの画面に到達できるか」はフレームとリンクで、「どのデータを読めるか」はモジュール権限で、それぞれ独立に管理する。
- FB-010（書込権限と連動しないボタン）への app 側の恒久対処を兼ねる。「読めるが書けない画面」を原則作らない。

### 3. 検索条件のレイアウト規約（経費申請で適用）

- 件名などの自由テキストは**専用行を与えて行いっぱい**（Width null=残余全部）。日付レンジは**内容がピッタリ入る固定幅**（340px）。ラベル列は折り返さない固定幅。
- 他画面へ同様の問題が見つかり次第、同じ規約で直す（今回は指摘のあった経費申請のみ）。

### 4. Logout の分離と確認ダイアログ

- app.css: サイドバーを flex 化し、Logout の nav-item を `margin-top:auto` + `position:sticky; bottom:0` で**常に画面下端**に表示（区切り線・背景付き）。CLB 本体 CSS が後勝ちするため `!important` が必要（実測）。
- index.html: capture フェーズの click リスナで `data-system="logout"` への クリックに**自前の確認オーバーレイ**（ログアウト/キャンセル）を挟む。ネイティブ confirm は使わない（ブラウザ自動テストを塞ぐため）。

## 影響

- URL: 変更なし（マスタ編集画面のみ /SalesFrame/Partner → /AccountingFrame/Partner に移動。新設 /SalesFrame/PartnerView・/SalesFrame/ProjectView）。
- ドキュメント: docs/tests/11・06・09 のメニュー表記を追随更新。
- CLB 製品提案: FB-010 追補・FB-024 新設（docs/12）。
