# ADR-0072: 仕掛品（未成業務支出金）の期末振替は「検収未了」を基準に洗い替える

- 日付: 2026-08-17
- 状態: 採用（ユーザー承認済み）
- 起点: BUG-0016。**期末に未完了案件の原価を仕掛品へ振り替える処理が無い。**
  `docs/03_機能スコープ.md` には作ると書いてありながら、機能が存在しなかった

## 背景（問題）

受託開発では、期をまたぐ案件の原価（工数・外注費・経費）が期末時点で発生済みなのに、
売上はまだ立っていない（検収が翌期）。この原価を**仕掛品（未成業務支出金）**として資産に振り替えないと、

- **当期の損益が過小**になる（費用だけ先に落ちる）
- **翌期の損益が過大**になる（売上だけ後から立つ）
- 期をまたぐ案件が多いほど、**期ごとの利益が実態と乖離する**

これは決算の必須処理であり、無いままでは「市販ソフト以上」を名乗れない。

## 決定

**期末に「検収が確定していない案件の原価」を仕掛品へ振り替え、翌期首に振り戻す（洗い替え）。**

### 「未完了」の定義 —— 検収の有無で判定する

**案件のステータスではなく、検収が確定しているかどうかで判定する。**

理由: **売上計上が検収基準（ADR-0008）だからである。** 収益の認識基準と費用の繰延基準を
同じ事象（検収）に揃えれば、**費用収益対応の原則がそのまま成立する。**
案件ステータスは人が手で更新する運用値であり、更新漏れがそのまま決算数値の誤りになる。
検収は伝票の存在という客観的な事実なので、判定がぶれない。

### 原価の源泉

| 源泉 | 拾い方 |
|---|---|
| 人件費 | 既存の人件費配賦（工数 × 人件費単価）。案件に紐づく分 |
| 外注費 | 案件に紐づく仕入先請求書（ADR-0064 で案件を持たせた） |
| 経費 | 案件に紐づく経費明細（ADR-0066 で明細が案件を持つ） |

### 洗い替え方式にする

- **期末**: `借方 仕掛品 / 貸方 各原価科目` を決算整理仕訳として起票
- **翌期首**: 同額の反対仕訳を自動生成して振り戻す

**残高を積み上げる方式にしない理由**: 積み上げ方式は「前期にいくら計上したか」を常に正しく
持ち続ける必要があり、**ADR-0068 で問題になった翌期繰越の陳腐化と同じ罠**を新たに作る。
洗い替えなら毎期ゼロから計算するので、過去の計上額が誤っていても当期に持ち越さない。

### 取消

**ADR-0070 に従う。** 期末振替の仕訳が締め前なら取り消して再実行できる。
締め済みなら取り消せず、当期に反対仕訳を起こす。
決算整理は「数字が固まるまで何度も打ち直す」性質のものなので、**締めるまでは再実行を許す**のが実務に合う。

## 帰結

- **不変条件を足す**: 期末の仕掛品残高 = 検収未了案件の原価合計（同一年度内）／
  翌期首の振戻額 = 前期末の振替額
- 案件別損益（BUG-0039 / M-1）とは**別物**である。案件別損益は案件の生涯を通した採算を見るもので、
  仕掛品は**期間損益を正しくするための決算整理**。両者は目的が違うので統合しない
- 「検収が確定していないが、実質完了している案件」は仕掛品に残る。
  **これは正しい**——検収基準を採る以上、売上が立っていない案件の原価は繰り延べるのが筋
- 前受金・着手金（ISSUE-0005）が実装されたら、**仕掛品と前受金が両建てになる案件**が出る。
  相殺しない（総額表示が原則）

## 却下した選択肢

- **案件ステータスで判定する** — 人が手で更新する運用値なので、更新漏れが決算数値の誤りに直結する
- **残高積み上げ方式** — 翌期繰越と同じ陳腐化の罠を新設することになる
- **進行基準（工事進行基準）で売上も同時に立てる** — 収益認識の基準そのものを変える話であり、
  ADR-0008（検収基準）の変更を伴う。**本 ADR のスコープ外**。必要になったら別途 ADR を起こす
