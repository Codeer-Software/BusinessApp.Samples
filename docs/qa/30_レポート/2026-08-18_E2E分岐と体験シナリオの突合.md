# E2E 分岐と体験シナリオの突合 — カバレッジの穴

- 実施日: 2026-08-18
- 方法: `docs/tests/11_E2Eテストシナリオ/分岐_*.md` から分岐 ID を機械抽出し、`docs/tests/20_体験シナリオ/` の
  各台本本文が参照する ID と突き合わせた。**読解と突合のみ**（実機・コード変更なし）。
- 集計単位: **親 ID**。`EXP-X04-1` `BNK-08-3` `COR-05-2` `PUR-05a` `RCV-09b` `EXP-S01b` `BNK-02b` のような
  枝番は親（`EXP-X04` 等）に丸めた。丸める前の実 ID 数は 143。
- 参照元から `docs/tests/20_体験シナリオ/README.md`（例示として 7 個の ID を挙げるだけの索引）は除外した。

## 1. 要約

| 指標 | 値 |
|---|---|
| E2E 分岐の総数（親 ID） | **123** |
| 体験シナリオが参照している分岐 | **96**（78.0%） |
| どの体験シナリオも参照していない分岐 | **27**（22.0%） |
| うち会計の正しさに直結（★） | **12** |

## 2. ID の付け方に関する事実（推測でなく観測）

- **分岐 ID を持つのは 6 フォルダだけ**。`00_初期設定` `06_案件・経営管理` `09_帳票検証` は
  基本シナリオのみで分岐ファイルが無く、**分岐 ID が 1 つも存在しない**。
- ID の形は 2 系統に割れている。**経費だけ `EXP-{R|S|P|A|X}nn` の 2 文字目に区分英字が入る**
  （`EXP-R01`）。他は `SLS-01` `JRN-05` のような `{3文字}-{2桁}` で統一。
- **定義場所も 2 系統**。ほとんどは見出し（`### RCV-07: …`）だが、`RCV-01〜06` は
  `02_販売/分岐_検収請求入金.md` の「実施済み分岐への参照」**表の行**でしか定義されていない。
- 枝番の付け方が 3 通り混在（`-1`／`a`／`b`）。`EXP-X04` は親に本文が無く枝番 `-1` `-2` だけが実体。
- **`11_E2Eテストシナリオ/README.md` の分岐網羅状況の表が腐っている**。02〜08 を「基本のみ（分岐は段階納品の次段）」と
  書いているが、実際には全フォルダに分岐ファイルがある。`01_経費精算/README.md` も「EXP-R/S/P/A/X 全 20 本」と
  書いているが実数は 25 本（2026-08-17 の R09〜R11・P06・S01b 追加が反映されていない）。

| 01_経費精算 | 25 | 21 | 4 | EXP-P03 / EXP-P06 / EXP-R11 / EXP-S02 |
| 02_販売 | 31 | 21 | 10 | SLS-02 / SLS-07 / RCV-02〜RCV-09 |
| 03_購買 | 9 | 8 | 1 | FBX-03 |

| 05_銀行 | 9 | 7 | 2 | BNK-01 / BNK-06 |
| 06_案件・経営管理 | 0 | — | — | （分岐 ID なし） |

| 08_決算 | 10 | 10 | 0 | — |

- 内訳の接頭辞: 02_販売 = SLS 8 + RCV 11 + RCR 6 + SES 6、03_購買 = PUR 5 + FBX 4、
  04_会計コア = JRN 12 + CSH 9 + IMP 7。
- **完全カバーの系統**: RCR（6/6）・SES（6/6）・PUR（5/5）・IMP（7/7）・CLS（10/10）。
- **穴が集中しているのは RCV（3/11）**。11 本中 8 本が未参照で、未カバー 27 本の 3 割を占める。

本レポートは ID 参照の有無だけを機械判定しており、**操作の実質的な重なりまでは判定していない**。

## 5. 逆方向 — 体験シナリオにしか無い観点

体験シナリオ 51 本のうち **19 本が分岐 ID を 1 つも参照していない**。うち以下のドメインは
**E2E 側に対応する分岐ファイル自体が存在しない**（＝期待値の正典が無い領域）。

| 体験シナリオのドメイン | 本数 | E2E 側の対応 |
|---|---:|---|
| 00_ポータルと通知（ポータルツアー・通知センター・直 URL ゲート） | 3 | 分岐なし（基本シナリオにも章が無い） |
| 09_経営管理（予算予実・案件損益・資金繰り予測） | 3 | `06_案件・経営管理/基本シナリオ.md` のみ・分岐 ID なし |
| 10_工数と案件（工数入力・案件マスタの権限） | 2 | 同上 |
| 11_マスタ_組織_権限（ユーザーと機能フラグ・部課と承認の追随・承認テンプレ・税制閾値） | 4 | 分岐なし（COR-04 が職務分掌に部分的に触れるのみ） |

- 残る 7 本は ID 未参照だが E2E に近い章がある: `01_経費精算/01`（基本 E-1）・`01_経費精算/04`（基本 E-2）・
  `01_経費精算/10_締め済み期間の申請`・`02_営業_受託/03`・`02_営業_受託/06_相殺入金`・
  `06_会計_仕訳と帳簿/01`・`07_銀行/01`。**ID タグの付け忘れの可能性が高い**（要確認）。
- とくに **`02_営業_受託/06_相殺入金` と `09_経営管理/03_資金繰り予測` は E2E 側に分岐が一切無い**。
  機能が後から入ったが期待値台帳が追いついていない形。
- `08_決算` だけは CLS 10 本が全て体験シナリオから参照されており、双方向に穴が無い。
